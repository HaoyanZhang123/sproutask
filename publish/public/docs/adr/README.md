# 架构决策记录（ADR）

一份 ADR 记录**一个**不可逆或影响面较大的决定：当时有哪些选项、为什么选它、放弃了什么。

状态取值：`Accepted`（已采纳）/ `Superseded`（被后续 ADR 取代）。

| 编号 | 标题 | 状态 |
|---|---|---|
| ADR-0001 | 采用"本地优先的桌面 Agent"架构 | Accepted |
| ADR-0002 | 交互形态：对话 + 可折叠教材阅读视图 | Accepted |
| ADR-0003 | 内容格式与本地存储实现 | Proposed |
| ADR-0004 | 教材装载方式：结构化按需装载 vs 向量检索 | Accepted |
