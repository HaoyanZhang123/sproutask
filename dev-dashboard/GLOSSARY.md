# 术语表

| 标准用词 | 指什么 | 别名/曾用名 |
| --- | --- | --- |
| 芽问 | 这个软件本身 | SproutAsk |
| 小芽 | 软件里陪学生读书、回答问题的助手 | AI 老师、机器人 |
| 今天 | 首页：接着上次、挑概念、看该复习什么 | 首页 |
| 学习 | 一次学习活动所在的地方：课本 + 题目 + 反馈 | 工作区 |
| 进展 | 回看学过什么、哪里要再练、什么时候复习 | 记录页 |
| 知识地图 | 全册章节地图 + 章级关系图 | 地图 |
| 我的课本 | 当前教材、来源与核对状态 | 教材库 |
| 概念 | 一条要掌握的内容，带课本页码出处 | 知识点 |
| 在学 | 正在学、还没答完 | 进行中 |
| 要再练 | 最近答得不太稳，值得再练一遍 | 需巩固 |
| 比较稳 | 已经答对过，但还会安排复习 | 初步理解 / 表现稳定 |
| 还没开始 | 没有作答或复习记录 | 未开始 |
| 自评 | 学生自己点"不确定 / 基本会 / 能解释"，与系统判断分开 | 自己觉得呢 |
| 出处 | 这段话来自课本第几页 | 来源、引用 |
| 未核实 | 内容还待人工核对，不能当稳定结论 | 候选内容 |
| 内容包 | 软件自带的七上内容（概念、活动、评分、关系） | 教材数据 |
| 学习台 | 学习页的布局：左页课本、右页练习 | 工作区 |
| 拍板 | 你在决策卡上选一个选项定下来 | 决定、定夺 |
| 验证 | 你亲手试用后明确说"我验证过了" | 实测 |
