# 芽问（SproutAsk）—— 陪初中生把生物课本读进去的提问小助手

## 项目简介

给初中生用的一个电脑小软件：它不替老师讲课，也不直接给答案，而是**一轮一轮地提问**，
让学生先自己答，再带着他去课本里核对。学生打开后先选"今天想做什么"（预习 / 复习 / 做题 / 拓展），
右侧的**教材窗**同时显示这一节要掌握的知识点、国家课程标准的对应要求，以及它们在课本第几页——
每一句话都能追到出处。

它主要服务两种人：**学生**（一个人对着电脑复习，不用等老师）和**项目负责人自己**（想看看
"AI 能不能不问着要答案、而是引导着学"）。所有对话与学习记录只写在这台电脑上，用学生编号、不记姓名。

## 使用流程

1. 下载并打开 :: 便携版双击即用、不安装；安装版装到自己账户下，不需要管理员 :: 证据: docs/releases/v0.2.0-alpha.md
2. 第一次打开先填模型钥匙 :: 软件自身不含钥匙，需要自己申请一个填进去；填错了会明确提示 :: 证据: src/renderer/src/components/ConfigPanel.vue
3. 小芽先问"今天想做什么" :: 四个按钮：预习 / 复习 / 做题 / 拓展，你选一个才开始 :: 证据: src/renderer/src/App.vue
4. 小芽提问，你先答 :: 每轮回复都很短，并以一个问句结尾；你说"直接告诉我答案"也不会给 :: 证据: src/core/agent/loop.ts
5. 右侧教材窗对照课本 :: 显示这一节的知识点、课标要求与页码；答案默认收起，先自己想想再点开 :: 证据: src/renderer/src/components/ReadingPane.vue
6. 关掉再打开，接着上次继续 :: 开场会提到你上次学到哪一节（记录就在这台电脑上） :: 证据: src/main/storage/jsonl-store.ts
