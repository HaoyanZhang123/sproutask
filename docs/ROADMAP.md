## 到校后需要回填的信息（影响 M2/M4）

- 教材版本与册次（决定内容工程的对象）
- 实习期间实际讲授的单元（决定聚焦范围，建议 1-2 个单元做深）
- 机房能否运行免安装 exe（决定课内可用性）
- 学生家用机 Windows / Mac 比例（决定 dmg 优先级）
- 指导教师与教务处态度、家长知情同意可行性（决定能否真正试用）

详见 `notes/到校调研清单.md`。

## 建议的开发顺序（按"最早能跑起来"排）

1. **M1**：先把"会说话的 Agent"跑通（提示词 + DeepSeek 客户端 + 评测）——不依赖教材、不依赖界面，最快见到效果
2. **M3**：套上最小对话界面（这里不依赖 Q3/Q4/Q5，因为可以先用内存态的假数据）
3. **M2**：教材版本确认后立即做内容工程（这是唯一被外部信息阻塞的事，越早确认越好）
4. **M4**：等 Q4/Q5 拍板后一次性实现存储与引导形态
5. **M5/M6**：打包、试用、收数据

> 提示：M1→M3 这条线**不会因为 Q3/Q4/Q5 未定而阻塞**，可以马上开始。
