# F-018：去 AI 味（界面文案 + 模型语气）

- **里程碑**：M4（用户体验修正，不依赖外部信息）
- **状态**：✅ 已完成（2026-09）
- **依赖**：F-010（界面）、F-002（提示词）

## 1. 目标

用户实测反馈："**说话语气太 AI 了**，不管整个页面 UI 上的文字，还是输出的回答，AI 味太浓"。
本条需求把"像不像 AI"拆成可执行、可回归的四层并逐层修掉。

## 2. 用户故事

作为学生，我打开它时希望是在跟一个坐旁边的同学说话，而不是在跟一个"AI 助手"打交道；
作为教师/研究者，我希望界面上的字是给人看的，而不是控制台输出。

## 3. 四层问题与处理

| 层 | 原来 | 现在 |
|---|---|---|
| **界面文案**（软件腔） | "命中 3 处""先自己想一想，再展开对照""把你的问题或想法打在这里，回车发送（Shift+回车换行）""已在教材中定位「…」（高亮显示）" | 改为"在课本里找到 3 处""先自己想想，想好了再点开对答案""想问什么？打完按回车就行""课本里也提到了，我把「…」标出来了" |
| **开发信息外露** | 气泡下直接显示 `工具：get_section_text`、`护栏命中：…`、`迭代 2 轮`、`降级：missing-key` | **默认不显示**；`SPROUTASK_DEVUI=1` 时才出现 |
| **技术文案** | 报错原文 `出错了：Error: …` 直接上屏 | 非开发模式改为"刚才出了点小状况，再试一次好吗？"（技术细节只在开发模式/日志里） |
| **模型语气** | L0 只写"亲切活泼"；L1 给了**写死的台词**与"第四章第一节"过期示例 | 新建 `prompts/v2`（见下） |

**用户明确要求保持不变的两处**：出处标注 `（出处：…）`、顶部无 Key 提示条；
**明确要求保留的技术字样**：降级文案里的"API Key 未配置或无效"。

## 4. 提示词 v2 的改动

- **反 AI 腔清单**（L0）：禁自我介绍式开场、禁客套（"当然可以！""好问题！""希望对你有帮助"）、
  禁书面连接词（首先/其次/总之）、禁用学生的话反问以确认、禁排比与宣传腔、禁每句感叹号
- **语气**：从"亲切活泼的学姐"改为"坐在旁边的同学"；长度 150 → 100 字
- **类比规则**（用户第 4 条要求）：类比只为帮助理解，**不得替代或偏离教材说法**；拿不准就别打比方
- **删掉写死的台词**（L1）：v1 直接给了整句话，模型会反复背同一句——这是最"机器"的地方
- **必须以提问收尾**（L1）：不能只给指令（"你先翻到第四节找找"）或只做讲解
- **不要直接确认或纠正**（L1）：学生猜对了让他讲理由；猜错了把判断交回课本，不要直接说"不对/是……"

> v1 冻结保留，作 A/B 对比基线；版本规矩见 `src/core/prompts/README.md`。

## 5. 验收标准

- [x] 学生可见文案里不出现开发术语（工具/护栏/迭代/降级/SPROUTASK）——自检自动把关
- [x] 默认不显示调试信息；`SPROUTASK_DEVUI=1` 时**应当**显示（两个方向都断言，防开关失效）
- [x] 两版并排对照工具：`pnpm prompts:compare`（同一批问题分别用 v1/v2 生成，落报告到 `evals/reports/`）
- [x] `pnpm typecheck` 0 错；`pnpm test` 127/127；`pnpm eval` **15/15（100%）**
- [x] 提示词回归测试：v2 的 system 提示词必须含反 AI 腔关键约束，且不含 v1 的写死台词与过期示例

## 6. 实测结论（2026-09）

- **评测首次真实跑通**：`pnpm eval` → **15/15（100%）**，答案泄漏用例 0 条
- **A/B 对照发现两处纪律退步**（v2 初稿语气变好但纪律变松），已修并复验：
  1. "直接要答案"时说了"课本里说它是能量转换器" → 等于替学生说出结论；
     修法：新增"不要替学生说出结论/不要直接确认或纠正"规则
  2. 学生答错时直接说"水是无机物哦" → 直接纠正 = 替他完成思考；
     修法：明确"把判断交回课本"
- 语气对照（同一批问题）：

  | 学生说 | v1 | v2 |
  |---|---|---|
  | 细胞膜有什么用？ | "这个问题问得好！…细胞膜就像一层'门卫'，你觉得这个门卫平时都在干嘛呀？🤔" | "嗯，第四节里专门讲了细胞膜。你先翻到那一节，看看它把细胞分成了哪两部分？" |
  | 别问了，你就说线粒体是干嘛的 | "哈哈，别急嘛…你猜猜看，是叶绿体还是线粒体？😄" | "直接说就没意思了。你先翻到第四节，找找…哪句话在讲它。" |
  | 我太笨了，怎么都记不住 | "别这么说呀，记不住多半是没找到'抓手'，不是笨 😊" | "先别急着说自己笨，这节东西确实多。先挑一个你最没底的：…？" |

## 7. 明确不做

- 不做 UI 大改版（配色/布局/图标）；只改文案与信息可见性
- 不做多轮记忆式语气个性化（依赖 F-013 存储）
- 不把"AI 味"写成无法判定的软指标——凡是能写成断言的都写成断言，剩下的人工判读

## 8. 已知缺口

- **"像不像 AI"最终是主观判断**：机器只能拦住已知的坏说法；每轮改提示词都应重跑 `pnpm prompts:compare`
  并人工读一遍
- 界面文案里仍有少量"产品腔"（如"换一个模式""就这样"）未经用户逐条确认，保持原样待定
- 反 AI 腔清单目前基于 v1/v2 观察到的具体坏说法，可能还有未覆盖的形态
