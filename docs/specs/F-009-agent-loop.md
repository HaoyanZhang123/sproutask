# F-009：Agent 循环（工具调用 + 答案泄漏护栏 + 降级）

- **里程碑**：M3
- **状态**：✅ 已完成（2026-09）
- **依赖**：F-002（提示词与模型客户端）✅、F-007（意图询问）✅

## 1. 目标

把"一次教学对话"跑成完整的 Agent 循环：组装上下文 → 调模型（带工具）→ 执行工具并回填 →
产出回答 → **答案泄漏护栏** → 命中则加严重写；全过程可离线测试、失败可降级。

## 2. 用户故事

作为产品，我希望模型即使偶尔想"直接给答案"，系统也能在交付给学生之前拦住并重写；
作为研究者，我希望每次拦截都有结构化记录，以便统计"护栏命中率"这一核心指标。

## 3. 输入与输出

| 项 | 说明 |
|---|---|
| 输入 | `LLMClient`、`ToolRegistry`、`PromptContext`（教材/课标/学情/模式与位置）、历史、本轮学生输入 |
| 输出 | `AgentTurnResult`：`reply`、`toolCalls[]`、`flags[]`、`iterations`、`guard{}`、`usage?`、`degraded?` |
| 涉及契约 | 复用 `Turn`、`TurnFlag`；**不新增契约** |

## 4. 实现要点

- `src/core/agent/loop.ts`：循环上限 5；工具调用按"assistant 携 tool_calls → tool 结果"协议回填；
  空回复给可读兜底且**不触发护栏重写**；模型异常转 `degraded` 返回（不抛给界面）
- `src/core/agent/tools/`：Zod 定义 + 自动转 JSON Schema；参数/JSON/执行错误一律**回填给模型自我修正**
  - `get_section_text`：按需取教材原文（避免整册注入）
  - `flag_for_teacher`：结构化记录"索要答案 / 偏离话题 / 超出教材"，供统计（**不做教师端**）
- `src/core/agent/guard.ts`：两层判定
  - 规则层（默认开）：直给措辞、"复述知识点要点片段"、整段无提问、空回复
  - 模型层（可选，默认关）：让模型判定"是否已给出最终答案"，失败时安静放过
- `src/core/llm`：`ChatMessage` 支持 assistant 携带 `tool_calls`；`toApiMessage` 导出以便离线单测协议
- 本轮**不写数据库**：持久化属 F-013（存储实现），由调用方负责

## 5. 验收标准

- [x] 文本回复一轮结束；工具调用能被执行、结果被回填（断言第二次调用的消息序列）
- [x] 工具失败（坏 JSON / 参数错 / handler 抛错 / 未知工具）不打断整轮，错误文本回填
- [x] 护栏：泄漏 → 加严重写一次并打标；重写后仍泄漏 → 保留标记、不再无限重试
- [x] 合格回复不触发重写（不浪费调用）
- [x] 模型异常降级为面向学生的中文提示（不含技术细节）
- [x] 循环上限被遵守（始终调工具时给可读兜底，不死循环）
- [x] `pnpm typecheck` 0 错；`pnpm test` 全绿
- [x] **mutation-check**：把护栏重写分支改坏 → 恰好 2 个护栏测试变红；还原后全绿

**实测结论（2026-09-22）**：
- `pnpm test` **79/79 通过**（8 个文件；本次新增 35 例：tools 14、guard 11、loop 10）
- mutation-check 见上（改坏 → 2 failed；还原 → 79 passed）
- **端到端**：用无效 Key 跑 `pnpm chat`（逐步写入 stdin），真实请求 DeepSeek 返回 401 →
  映射为 `auth` → 输出"我还没拿到'思考的钥匙'…"，并显示 `降级（auth）｜迭代 1 轮`；
  证明接线、网络可达、鉴权头正确、降级链路学生安全

## 6. 明确不做

- 不做真实存储落库（F-013）、不做界面（F-010）
- 不做模型层护栏的默认开启（成本翻倍；先靠规则层 + 评测观察）
- 不做多智能体编排

## 7. 已知缺口与遗留问题

- **"流式输出"与"护栏重写"冲突**：若先流式显示，护栏判定后被重写的内容无法撤回。
  本需求在 `pnpm chat` 中改为"等等护栏通过再整段显示"；**F-010 界面需求需正式决定**
  （缓冲后整段显示 / 先显示"想一想"状态）
- 规则层护栏是**启发式**：靠要点片段与措辞匹配，可能误判（学生自己说出要点时也命中）
  或漏判（改述式给答案）。缓解：`evals/cases/` 持续扩充 + 可选模型层；误判率待实测统计
- 模型层护栏的判定提示词尚未在真实数据上调优
- 工具只有 2 个（取原文、打标记）；出题、生成互动实验、记录掌握度属 M4
