# F-014：前后测问卷、评分说明与知情同意材料

- **里程碑**：M5（已提前执行：不依赖外部信息，且问卷是研习数据主渠道）
- **状态**：✅ 已完成（四份材料齐备；3 项待人工确认，见验收标准末条）
- **依赖**：无（目标单元已定为人教版七上 第二单元第一章第四节「细胞的生活」）

## 1. 目标

产出一套**可直接打印使用**的研习材料：前测问卷、后测问卷、教师用维度对应表与评分说明、
家长知情同意书与使用公约。它们既是研习的数据采集工具，也是伦理合规的载体。

## 2. 用户故事

作为研究者（实习生），我希望在实习前就拿到定稿问卷与同意书，
以便到校第一周即可提交指导教师审阅、随家长信发出，而不是临近试用才仓促准备。

## 3. 输入与输出

| 项 | 说明 |
|---|---|
| 输入 | `docs/研习设计.md`「问卷设计规范」「先例约束」；目标单元的概念清单 |
| 输出 | 四份 `docs/研习材料/*.md`：前测问卷、后测问卷、教师用说明、知情同意材料 |
| 涉及契约 | 无（纯研习材料，不进产品运行时） |

## 4. 实现要点

- 依先例规格：李克特五点、含反向题、附录给"维度—题号对应表"、报告信效度
- 概念题前后测**使用同一套**（便于配对比较），另加 2 道迁移题仅后测使用
- **只收编号不收姓名**（与产品合规一致）
- 每个判断标准/阈值**必须标文献**（指导教师批注第 2、3 条）；
  引用先经 Crossref 核验到 DOI，禁止凭记忆书写
- 学校名称**匿名**（指导教师批注第 1 条）

## 5. 验收标准

- [x] 四份材料齐备，可直接打印（题干、选项、作答栏齐全）
- [x] 反向题已标注并给出反向计分说明；维度—题号对应表独立成页（不发给学生）
- [x] 所有阈值/判据均带参考文献（含 DOI）
- [x] 材料中不出现校名、不收集姓名
- [x] 术语与产品一致（学习模式、引导而非告知）
- [ ] **待人工确认**：字数/格式要求、是否增加教师视角数据（交叉对比）、匿名写法是否需与指导教师确认

**实测结论（2026-09）**：16 条参考文献经 Crossref API 逐条核验取得 DOI（核验命令与日期见
`docs/研习材料/F-014-教师用（维度对应表·评分·参考文献）.md`）。

## 6. 明确不做

- 不做在线问卷（本项目用**纸质问卷**，2026-09 决策）
- 不做问卷统计脚本（M6 的数据整理另立需求）
- 不做教师访谈提纲（**待定**：取决于是否要做"学生问卷 × 教师观点"交叉对比）

## 7. 已知缺口与遗留问题

- 概念题已按**人教版七上「细胞的生活」**改写（2026-09）；教材用词仍建议拿到纸质教材后**逐题核对**
  一次（铅笔标记的"线粒体/叶绿体""有机物/无机物"等表述），核对后再定稿打印
- 未做问卷预试（试填）：理想情况下应找 2–3 名学生试填检查题意歧义，实习第一周补做
- 认知负荷与依赖维度为**自编题**，仅参考已有量表的结构，未直接使用成熟量表全文，
  信效度需在实际数据上检验（先例同样做法：改编 + 检验）
