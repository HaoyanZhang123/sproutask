# 架构决策记录（ADR）

一份 ADR 记录**一个**不可逆或影响面较大的决定：当时有哪些选项、为什么选它、放弃了什么。
写 ADR 的时机：改领域契约、改分层规则、选定被搁置的技术方案（Q3/Q4/Q5）、更换关键依赖。

状态取值：`Proposed`（待拍板）/ `Accepted`（已采纳）/ `Superseded`（被后续 ADR 取代）。

| 编号 | 标题 | 状态 |
|---|---|---|
| ADR-0001 | 采用"本地优先的桌面 Agent"架构 | Accepted |
| ADR-0002 | 交互形态：关卡式 / 对话式 / 混合 / 对话+教材视图（四选一） | Proposed（待拍板 Q5） |
| ADR-0003 | 内容格式与本地存储实现 | Proposed（待拍板 Q3/Q4） |
