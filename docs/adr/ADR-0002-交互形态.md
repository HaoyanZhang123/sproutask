# ADR-0002：交互形态——采用方案 D（对话 + 可折叠教材阅读视图）

- **状态**：**Accepted（2026-09 拍板，采纳方案 D）**
- **日期**：2026-09（同日追加方案 D 并拍板）

## 决策（2026-09）

**采纳方案 D：对话引导 + 教材阅读视图**，规则如下：

1. 主界面为**双区**：教材阅读区 + Agent 对话区（借鉴同类开源 Markdown 阅读器的布局与交互）
2. 教材中的"想一想 / 讨论 / 答案"采用**折叠块**：答案默认收起，学生先自己答再展开对照
3. Agent 回答提到出处时，**教材阅读区自动滚动并高亮对应段落**
4. **按学习模式自动调整布局**：复习 / 做题时**折叠（收起）教材阅读区**，把空间让给对话；
   预习 / 拓展时展开，供学生对照原文
5. 学生可在教材区划选文字 → "问小芽"，带着选中内容提问
6. 不做关卡地图、不做游戏化包装

**理由**：无游戏化风险、教师易接受；有"对照教材"的学习场景感；与核心原则"答案必须有出处"
天然咬合；折叠块 / 全文搜索高亮 / 滚动定位均为成熟交互，技术风险低（已有同类开源项目验证）。

**布局细节**（折叠触发、双栏在小屏上如何退化）在实现阶段细化。

## 背景

早期设计把"知识点闯关"当作 Agent 的核心机制（认为它是 Agent 与聊天机器人的分水岭），
但开发者对"关卡"这种形态存疑：初中生是否会因此觉得幼稚？教师是否接受"游戏化"包装？
"闯关地图"是否只是好看而增加实现与维护成本？

## 候选方案（四个）

### 方案 A：关卡式（显式编排）
- 教师预先为知识点编排"关卡"（每个关卡含诊断问、引导问、变式题、过关标准）
- 界面提供闯关地图与进度可视化；Agent 按关卡推进并结算
- ✅ 教学路径可控、进度可见、学习数据规整（每关的通过率）
- ⚠️ 编排工作量大；游戏化包装可能不被师生接受；灵活性低（学生跳不过去）

### 方案 B：对话式引导（无显式关卡）
- 教师只提供**知识点清单 + 前置关系 + 常见误区**；不编排任务序列
- Agent 依据掌握度与教学进度，自主决定下一步问什么、何时给提示、何时推进
- ✅ 编排负担小；交互自然；更贴近"家教"而非"游戏"
- ⚠️ 过程不易可视化；Agent 的策略质量更依赖提示词工程；教学对比实验的条件不易控制

### 方案 C：混合（B 为底，A 为可选皮肤）
- 领域层只维护"知识点 + 掌握度"，编排层可选：教师想用关卡就填关卡定义，不想用就纯对话
- ✅ 两种形态共用同一地基，随时可切换
- ⚠️ 需要多写一层编排抽象（但接口很薄）

### 方案 D：对话引导 + 教材阅读视图（2026-09 新增，借鉴同类开源阅读器而来）
- **不游戏化、不编排关卡**：左侧/上方是**教材原文阅读视图**，右侧/下方是 Agent 对话
- 教材中的"想一想 / 讨论 / 答案"采用**折叠块**：答案默认收起，学生先自己答、再展开对照
- Agent 回答里提到出处（"见第四章第一节"）时，**教材视图自动滚动并高亮对应段落**
- 学生也可以在阅读视图里划选一段文字 → 直接送给 Agent 提问
- ✅ 没有"幼稚的游戏化"风险，教师容易接受；有"学习场景感"（对照教材）而非"聊天感"；
  与"答案有出处"这条核心原则天然咬合；实现上复用成熟的 Markdown 阅读器交互模式
  （折叠块 / 全文搜索高亮 / 滚动定位），技术风险低
- ⚠️ 需要维护"教材原文 → 结构化 Markdown"的内容管线（含把答案部分标成可折叠）；
  界面比纯聊天复杂；需要处理"对话与教材视图的联动"（滚动/高亮同步）

**参考依据**：同类开源 Markdown 阅读器的实践——
折叠块（`<details>`，展开状态在列表回收后仍能保持）、中文全文搜索命中高亮、会话与滚动位置记忆，
恰好覆盖方案 D 所需的交互；其中滚动位置恢复的多轮收敛算法可直接复用。

## 后果与后续

1. **不需要** `src/core/orchestration/` 编排层（方案 A/C 才需要）——省掉一层抽象
2. "关卡"永久不进领域契约，领域层只维护"知识点 + 掌握度"
3. 教材阅读视图由候选转为**正式需求**，与 Agent 循环一并推进
4. 新增工作量集中在：教材原文 → 结构化 Markdown 的管线（含把答案标成可折叠）、
   对话与阅读区的联动（滚动/高亮同步）、按模式自动折叠布局
5. 需在实现时细化：折叠触发时机、小屏（机房低分辨率）下双栏如何退化

## 留待观察（不阻塞）

- 学生实际是否愿意对照教材原文——若只看对话不看教材，D 的复杂度收益下降
- 机房场景下双栏在小屏幕是否够用（必要时退化为标签页切换）
- 折叠答案的默认状态（收起 vs 部分展开）在学生中的实际使用情况
