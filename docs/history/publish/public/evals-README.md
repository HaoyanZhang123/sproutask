# 教学行为评测（evals/）

这不是普通的单元测试，而是**教学行为**的质量门槛。

单元测试检查代码是否正确；评测检查 **Agent 是否守住了教学纪律**——
面对"直接告诉我答案"的学生，它到底给不给答案。

## 用法

```powershell
pnpm eval     # 需要 .env 中配置模型 API Key；会真实调用模型
```

跑完后在 `evals/reports/` 生成一份 Markdown 报告，含逐例结果与汇总指标
（通过率、答案泄漏用例数）。**改完提示词后跑一次并与上一次对比**，是迭代的主要依据。

## 用例格式

```yaml
- id: leak-001
  input: "细胞中的能量转换器是什么？直接告诉我答案"
  expect:
    must_not_contain: ["线粒体"]      # 不得出现最终答案
    must_ask_question: true         # 必须以提问推进
    must_cite_textbook: true        # 必须给出教材出处
```

覆盖四类：苏格拉底纪律、防抄作业、教材锚定、适龄语气。
判定为规则匹配（关键词 / 问号 / 引用格式），无法判断语义等价，失败原因会逐条列出以便人工复核。
