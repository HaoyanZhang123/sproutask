# 芽问 SproutAsk v0.2.0-alpha

本地优先的初中生物学习 Agent：它不代替老师讲课，而是**提问、等你先答、再带你去课本里核对**。

## 这一版新增

- **应用图标与版本信息**：exe 与安装包带上了自己的图标，属性里能看到
  「SproutAsk / HaoyanZhang123」
- **学习数据留在本机**：每次打开的会话各自一个文件、逐轮追加保存；掌握度的变化也逐条记录。
  关掉再打开会记得你上次学到哪一节。数据只写在自己的电脑上，用学生编号、不记姓名
- **随包教学内容结构**：知识点、课程标准要求、印刷页出处随安装包一起分发
  （**教材原文不随包**——那是版权内容，只留在开发者本机）
- **教材窗的诚实提示**：本机没有教材正文时，界面明确提示「请对照课本第 X 页」，
  不会拿占位文字冒充课本；对话里也不会编造课本原句，而是请学生念出课本段落再据此引导
- **课标约束**：本节对应的课程标准条目（如「细胞是生物体结构和功能的基本单位」）随内容给出，
  每句话都能追到出处

## 下载

- `SproutAsk-0.2.0-win-x64.exe` —— **便携版**：双击即用、免安装（机房权限受限时用这个）
- `SproutAsk-Setup-0.2.0-x64.exe` —— **安装版**：装到当前用户目录，不需要管理员权限，可正常卸载

## 第一次使用

1. 打开后先填 DeepSeek API Key（软件本身不含 Key，需要自己申请一个）
2. Windows 可能提示「已保护你的电脑」→ 点「更多信息 → 仍要运行」
   （**本版未做代码签名**，系统不认识发布者；这不是病毒）
3. 选一个模式（预习 / 复习 / 做题 / 拓展），按提示把课本翻到对应页

## 已知限制

- 只做了 Windows 版；macOS 版尚未构建
- **学生机上看不到教材正文**（版权原因不随包）：请对照自己手里的纸质课本使用
- 内容只覆盖人教版七年级上册第一单元第二章第四节；其余单元待后续版本
- 未做代码签名；本版是单机自用形态（没有教师端）

## 隐私

不联网收集任何数据；对话与学习记录只写在本机 `%APPDATA%\sproutask\data`；
只用学生编号（如 `S00`），不保存真实姓名。
