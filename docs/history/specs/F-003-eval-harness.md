# F-003：评测集与 `pnpm eval` 报告

- **里程碑**：M1
- **状态**：✅ 已完成（骨架与判定逻辑实测通过；真实跑批待配 Key）
- **依赖**：F-002 ✅

## 1. 目标

把"Agent 是否守住教学纪律"变成可量化、可回归的指标，而不是靠感觉。
评测结果同时是研习报告的证据（提示词迭代前后对比）。

## 2. 用户故事

作为研习者，我希望每次改动提示词后都能得到一份"答案泄漏 / 是否反问 / 是否给出出处"的报告，
以便在论文里说明"v2 比 v1 少泄漏了多少次答案"。

## 3. 输入与输出

| 项 | 说明 |
|---|---|
| 输入 | `evals/cases/*.yaml`（输入 + 期望） |
| 输出 | `evals/reports/<日期>-<PROMPT_VERSION>.md`（逐例通过/失败 + 汇总指标） |
| 涉及契约 | 无新增 |

## 4. 实现要点

- 用例格式（见 `docs/CONVENTIONS.md`）：
  `must_not_contain` / `must_ask_question` / `must_cite_textbook` / `max_chars`
- 判定逻辑放 `src/core/eval/runner.ts`（纯函数，可单测）
- `scripts/eval.ts` 加载用例 → 调模型（需 Key）→ 汇总 → 写报告
- **无 Key 时**：明确报错并提示如何配置，不静默跳过
- 报告同时输出**答案泄漏率**（护栏相关）与失败原因，便于定位提示词问题

## 5. 验收标准

- [x] `pnpm eval` 能产出 Markdown 报告（含逐例结果与汇总）——报告渲染已有单测
- [x] 判定逻辑有单测覆盖（含边界：空回复、禁用词、超长回复、缺出处）
- [x] 用例覆盖四类：苏格拉底纪律（4）、防抄作业（3）、教材锚定（3）、适龄语气（3）
- [x] 报告文件名带提示词版本，便于版本对比
- [x] 无 Key 时明确报错并退出（实测 exit code 1 + 中文提示，不静默跳过）
- [x] **真实跑批**：✅ 已完成（2026-09-26）：15 条用例真实调用模型，15/15，报告在 `evals/reports/`

- 不做自动化调参/提示词搜索
