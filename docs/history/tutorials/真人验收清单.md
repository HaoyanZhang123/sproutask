# 真人验收清单（拿鼠标走一遍，约 15 分钟）

> 给谁用：项目负责人（不需要编程基础）。
> 为什么要人来做：自动化自检能验"代码有没有按设计跑"，**验不了"人用起来顺不顺、看着舒不舒服"**——
> 排版、字体、按钮好不好点、话术像不像老师，这些只能靠人看。
> 怎么用：照顺序做，每步看"应该看到什么"；不对就把"实际看到什么"记在最后一列，发我即可。

## 0. 准备（2 分钟）

1. 把 `release\SproutAsk-0.1.0-win-x64.exe` 拷到桌面（这个文件是**便携版**：双击即用，不安装、不写注册表）。
2. 双击打开。**第一次打开会比较慢**（5–10 秒），因为要解压自身，属正常。
3. 如果 Windows 弹出蓝色"已保护你的电脑"（SmartScreen）：点**更多信息 → 仍要运行**。
   （原因：我们没有买代码签名证书，Windows 不认识这个发布者。这是你之前定下的"先不买证书"的代价，不是病毒。）

## 1. 首次运行：配置模型 Key

| # | 做什么 | 应该看到什么 | 实际 |
|---|---|---|---|
| 1.1 | 首次打开 | 出现"配置"面板，要求填 DeepSeek API Key（不是直接进对话） | |
| 1.2 | 填一个**故意错的** Key（随便几个字母），点保存/测试 | 明确提示连接失败，**不是**卡住或白屏；提示里**不该**出现你填的那串 Key | |
| 1.3 | 填正确的 Key，保存 | 提示保存成功；界面进入正常可用状态；**界面上任何地方都看不到 Key 全文** | |
| 1.4 | 填一个**改过的接口地址** + 空的 Key | 提示要你重新填 Key（不允许把旧 Key 用在新地址上） | |

## 2. 开场与四种模式

| # | 做什么 | 应该看到什么 | 实际 |
|---|---|---|---|
| 2.1 | 重新打开该软件 | 开场是小芽先说话，并**问你今天想做什么**，给出四个按钮：预习 / 复习 / 做题 / 拓展 | |
| 2.2 | 第二次打开时 | 开场里会提到**上次学到哪一节**（"上次你在：……"）——这是"关掉再打开还记得" | |
| 2.3 | 分别点四个按钮 | 每种模式都能进入对话，且第一句话的语气与模式相符（预习=引导你先看，复习=查漏，做题=不给答案，拓展=联系生活） | |

## 3. 一轮真实对话（重点看"像不像老师"）

| # | 做什么 | 应该看到什么 | 实际 |
|---|---|---|---|
| 3.1 | 选"复习"，输入：`细胞的生活需要什么？` | 回复**不超过 200 字左右**、结尾是**一个问句**、要求你翻课本某处 | |
| 3.2 | 直接索要答案：`你直接告诉我答案吧，别问了` | **不给答案**；把问题交回课本；仍以问句收尾 | |
| 3.3 | 说：`我答：细胞壁控制物质进出，对吗？` | 不确认错误说法、也不生硬否定；引导你回课本核对 | |
| 3.4 | 追问超纲内容：`DNA 双螺旋是什么样？` | 说明课本本节没讲、不展开；**不编造**课本里没有的内容 | |
| 3.5 | 看一眼回复里有没有奇怪的符号 | 不应该出现 `:::think`、`<!--`、`##` 这类标记（那是给程序看的，不该给学生看） | |

## 4. 阅读视图（右侧教材窗）

| # | 做什么 | 应该看到什么 | 实际 |
|---|---|---|---|
| 4.1 | 点"展开教材" | 右侧出现教材正文 + 搜索框；**左右两栏各自滚动**（页面整体不出现滚动条） | |
| 4.2 | 看正文 | 是**第四节 细胞的生活**的正文（不是占位示例文字）；段落之间有空行，读得下来 | |
| 4.3 | 找"讨论 / 议一议"的位置 | 这些是**可折叠块**；答案块**默认收起**（先自己想，再点开对照） | |
| 4.4 | 搜一个只在答案里出现的词（例如"克隆羊的实例"） | 只提示"在折叠内容里找到"，**不自动翻开**；点"展开看看"才展开并高亮 | |
| 4.5 | 看页面底部 | 有知识点与**页码出处**（如"第 28 页"），能对得上手里的课本 | |

## 5. 数据留在本机（研习要用）

| # | 做什么 | 应该看到什么 | 实际 |
|---|---|---|---|
| 5.1 | 关掉软件，再打开，聊一两轮 | 对话正常；开场仍记得上次位置 | |
| 5.2 | 打开文件夹 `%APPDATA%\sproutask\data` | 能看到 `students.jsonl` 和 `S00\sessions\*.jsonl`（每次打开一个文件），内容是你刚才说的话与回复 | |
| 5.3 | 用记事本打开其中一个会话文件 | 一行一条记录、**没有你的真实姓名**（只有编号 S00）；教材原文不在这些文件里 | |
| 5.4 | 联网检查（可选） | 断开网络后再发消息：应给出**友好提示**而不是报错堆栈；恢复网络后能继续 | |

## 6. 卸载与清理

| # | 做什么 | 应该看到什么 | 实际 |
|---|---|---|---|
| 6.1 | 便携版：直接删掉 exe | 删掉即卸载完成（不残留程序） | |
| 6.2 | 安装版（`SproutAsk-Setup-0.1.0-x64.exe`）：安装后从"设置→应用"卸载 | 能卸干净；**数据目录按设计保留**（研习数据不因卸载而丢，需要手动删） | |

## 记录与反馈

- 任何一步"看到的和预期不一样"，就写在这一步的"实际"列里；**不用判断是不是 bug**，描述现象即可。
- 特别希望你留意的三点：① 话术像不像一个耐心的生物老师；② 教材窗读起来累不累（字号/行距/滚动）；
  ③ 有没有"它其实在偷偷给答案"的感觉。
- 说明：本清单**不覆盖 macOS**（你已决定先不做）；自动化能覆盖的部分见 `selftest-result.json` 与
  `docs/PROGRESS.md` §4，本清单只负责人眼能看、程序看不到的那些。
