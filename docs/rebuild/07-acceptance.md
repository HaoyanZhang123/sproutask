# 逐项验收与闭环标准

> 这是后续执行的验收规范，不是本次已通过结果。范围以[产品契约](01-product-contract.md)为准，状态与数据以[公共契约](05-data-contracts.md)为准，报告用[交回模板](09-report-template.md)。

## 1. 完成等级与举证规则

L0=读到文档；L1=静态实现/校验；L2=离线单元/契约与真实本地服务；L3=真实教育UI的模拟模型闭环；L4=真实DSH+真实模型+真实教材的交互；L5=实际Windows产物在独立用户数据目录运行。L1/L2/L3不可冒称L4，开发态通过不能代替L5。

每条AC结果只允许PASS / FAIL / BLOCKED / NOT_RUN。NOT_RUN、BLOCKED不算通过，不纳入“全绿”分母。报告必须保存执行时间、代码指纹、命令/输入、模型与内容版本、输出路径/hash、断言、人工判读与剩余问题。模型流式文本、截图好看、页面存在、历史日志都不能单独证明学习闭环成立。

全目标完成=下表所有本期AC满足所列级别+T17复核；缺原PDF、预算、正当凭据、DSH官方来源或账号准入时应报告具体受阻项，不缩范围、不制造完成声明。

## 3. 三个闭环门

G1（T13）：首节真实闭环。使用已审核真实首节，提供一条正确、一条误概念、一条主动解释、一条带提示后作答路径；至少一次跨concept导航；上传与图示可用；重启保持状态。所有服务通过实际DSH/教育API，禁止页面内硬编码“已掌握”。G1通过不表示全册完成。

G2（T14+T15）：全册就绪。先核真实目录、概念inventory与范围排除，再逐节核解释、关系、来源、活动与rubric。结构引用全量验证；概念与关键图科学含义逐项来源对照；每章真实互动抽样，不能只在第一节跑live。若专家/学生研究未做，结果明确未做，不阻断工程交付但不声称教育收益。

G3（T16+T17）：实际产物。Windows标准用户+独立userData、无项目根.env、无开发机依赖路径；分别运行便携与安装产物，验证全册结构、用户导入PDF、OCR、真实DSH、账户、作答、重启恢复。只验证unpacked开发产物不算验过要交付的exe。

## 4. 教学行为判读计划

T15至少覆盖12类：正确解释、核心误解、只背术语、连续答不出、请求完整解释、只要答案、受挫、无前置、已看答案再答、教材与学生说法冲突、模糊图片、跨章迁移。先固定场景和rubric，再跑两个独立轮次；同一用例失败不能删除或放宽以求全绿。T15记录每轮结果、原回复、来源与失败判读，修复后新报告保留旧失败。额外覆盖每章至少一次真实互动；真实调用受已授权预算约束，未足预算列BLOCKED而不是减少分母。

重要学科事实错误、捏造出处、确定性瞎判模糊图、破坏数据、秘密泄露、绕过DSH均属阻断问题。轻微措辞/布局问题列明影响与修复；未经用户批准不能带阻断问题交付。两轮是工程回归稳定性检查，非统计意义学习实验。

## 5. 内容覆盖台账

T05先制作首节，T14获取全册真实目录冻结coverage-manifest v1：每节source范围、concept清单、目标/rubric/活动/图/先修关系的覆盖、排除项与理由。首期目标是概念教学，不要求复刻每个练习与所有拓展框；但不能把不想做的核心概念排除。变更分母要有来源、差异与审核记录，T15独立比较实际目录，不能作者自改分母自称100%。

覆盖率：章节覆盖=有概念包且来源核对的目标节/冻结目标节；概念可学覆盖=解释+基础及变式活动+rubric+出处齐全概念/冻结概念；关系审核覆盖=已审关系/候选关系（被拒关系记录去向，不能悄悄丢）。每页至少有处理状态，OCR空白需有原因，不能把识别漏页视作原书空白。

## 6. 测试运行与证据存放

功能卡并行时至少运行自己范围typecheck:task、test:task和冻结test:contracts；主控全局写屏障后运行全量typecheck/test，集成阶段运行全部离线命令。涉及旧代码才增加旧根质量门。执行命令以T01冻结脚本为准，不能使用编写交接时尚不存在的命令声称通过。

非敏感交回报告写到docs/rebuild/reports/Txx.md（未来创建）；原教材/图片/真实对话详细证据写education/.local/evidence/<task>/<run>/，Git只留匿名摘要、hash与本机可解析路径。每个报告标明哪些证据是机器本地依赖，换机器需哪些输入。输出截图须遵守执行环境capture-sharp技能；不要截图密钥/个人信息。mock UI证据需醒目标mock。

实时模型测试默认预算未授权为0。可先实现全部离线路径并出具live运行计划，用户补授权后补齐L4/L5。最终真实验收不能用此默认约束作为省略L4的理由，必须真实补测或诚实BLOCKED。
