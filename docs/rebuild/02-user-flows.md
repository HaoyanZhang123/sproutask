# 学生用户流程与界面行为

> 本文描述目标体验及后续验收应观察到的行为，不是现有应用的实测报告。范围、内容覆盖和 R01–R18 见[产品契约](01-product-contract.md)；公共字段见[数据契约](05-data-contracts.md)，真实运行与权限见[DSH 集成契约](04-dsh-integration.md)，验收落点见[验收方案](07-acceptance.md)。不预设视觉库、数据库或图形组件。

## 1. 页面、入口与共同上下文

首页（今天）承担继续上次、地图、复习三个主要动作。常驻主导航为今天、学习、进展；教材库与知识地图仍然真实可用，从今天页与设置页进入，一次点击可达；复习使用学习页的复习模式，不另建一套学习系统。

| 页面或视图 | 学生要完成的事 | 主要出口 |
|---|---|---|
| 首用与身份视图 | 进入自己的本地记录，了解本地保存与云端反馈的区别 | 首页、教材库；模型服务未就绪时仍可读本地材料 |
| 首页 | 决定继续上次、找概念或复习 | 恢复工作区、地图、复习范围选择 |
| 教材库 | 选择匹配版本，查看材料可用性、出处及审校状态 | 当前教材地图、阅读材料、导入或重新关联 |
| 地图 | 按真实目录找位置，查看局部概念关系与当前证据 | 概念详情、学习或复习工作区 |
| 工作区·学习 | 对照材料理解概念，尝试、求助、纠错并收尾 | 地图、记录、首页、相关概念 |
| 工作区·复习 | 按自选范围回忆与作答，查看薄弱点及本轮结果 | 复习范围、地图、记录、首页 |
| 记录 | 回看活动、理解证据、自评、复习历史与变化原因 | 只读证据详情、恢复未完成活动、新一轮学习或复习 |
| 出处/材料详情 | 确认内容来源、印刷页与 PDF 页序、版本及审校方式 | 返回原概念和原活动位置 |

所有学习页面用学生话显示当前概念/范围、进度与保存结果；内容包版本、内部 id、工具轨迹不进入学生界面。材料页可见来源和审校状态；学生无需先懂“插件”“工具调用”或“Skill”才能使用。开发入口移出学生导航，权限由后端约束，不能依靠隐藏按钮代替限制。本期不新增多学生账号管理或学校多租户界面；本地学习身份与模型消费账号分别处理。

## 2. 共用 UI 状态与交互规则

| 状态 | 界面应显示 | 允许的动作与数据处理 |
|---|---|---|
| 初次加载 | 说明正在打开什么，保留页面标题与返回入口 | 可返回；不显示虚构的教材、活动或成绩占位值 |
| 空态 | 说明为什么为空及一个明确下一步 | 无教材去教材库；无记录去地图；无待复习可自选范围 |
| 正常可用 | 内容、活动或记录及其上下文 | 继续、返回、切换范围；保存状态跟随实际写入结果 |
| 请求处理中 | 可辨认的进度阶段与取消入口 | 输入先保留；同一活动不重复提交；不能用假精度进度条掩饰未知耗时 |
| 待审核/待核实 | 标出对象、原因及未核实范围 | 可看来源、返回基准；候选内容仅在明确选择后试用，保留标识 |
| 局部缺失 | 哪些材料/图/出处不可用，哪些仍可用 | 继续可用部分或重新关联；不让一张图失败造成整页白屏 |
| 离线或云服务不可用 | 已有材料与记录仍可看；本次无法生成或获取实时反馈 | 草稿本地保存，稍后由学生重试；不自动联网补发，不伪造模型回复 |
| 操作失败 | 用中文说明影响和可采取的动作 | 重试、改文字、重新选材料或返回；不展示密钥、堆栈和内部路径 |
| 已取消 | 明确本次请求未继续，输入是否已保存 | 可修改后重试或离开；取消不记为错答或活动完成 |
| 保存失败 | 明确“尚未保存”，保留当前输入 | 重试保存、复制文字；离开时说明丢失风险，不能标为已保存 |
| 恢复时内容不兼容 | 展示原版本与当前变化，说明哪些位置不能恢复 | 可看旧记录、重新关联匹配内容或开始新活动，不静默迁移证据 |

取消可能无法撤销已发送的云端请求，也不保证撤销费用；需要时以短句如实说明。取消之后的迟到反馈不能写回已取消活动、其他教材或另一个学生的记录。网络恢复不能自动重新上传图片或草稿；学生明确重试后才继续。

每个反馈或保存状态既有可见文字，也能被辅助技术读取。错误不清空输入，不把焦点跳回页面顶部；重试成功后清除过期错误。查看材料与记录不因模型服务连接失败而被统一登录弹窗拦住。

## 3. 逐页流程

### 3.1 首用：身份、教材、已学范围与短诊断

1. 学生首次打开产品，看到简短说明：记录保存在这台电脑；智能反馈需要云端服务，相关问题、作答及所选材料可能发送到已配置的服务。不能写“全部数据从不离机”。
2. 按身份方案进入学生自己的本地记录。学生凭据只用于学生身份或教育功能授权；模型服务连接状态独立显示，不能把学生账号当成模型账号。凭据发放、初始配置和恢复方式由[DSH 集成契约](04-dsh-integration.md)限定，不在本流程臆定统一密码或学校平台。
3. 选择教材库中的匹配教材，查看版本、来源及基准可用情况；若尚无可用材料，转教材库接入流程，不生成空壳全册地图。
4. 按真实目录选择“我学过的范围”，可选部分章节或概念、全未学、暂不确定。明确说明这是学生自述，后续可修改，不将所选内容一键标为理解稳定。
5. 展示短诊断的所选范围、题数及可随时结束的说明；题数来自实际可用题目，在开始前可见，本契约不虚构固定科学阈值。学生可开始或“先看地图”。
6. 诊断逐题使用本期支持的活动形式，允许提示、解释、跳过。使用帮助后标记为有帮助的作答；结束时只说明实际观察到的表现及未测范围。
7. 首页或地图显示初始建议：从尚无证据的概念开始、巩固已暴露问题，或自由选择。短诊断未做、失败或中止都不锁住学习。

**状态与返回：**凭据不通过时可重试并保留非敏感输入，不回显凭据。模型未连接或离线时可保存已学范围、查看已有材料、填写本地草稿；没有有效批改的回答保持待反馈。中断诊断后保留已作答、题目版本及未完成位置，再进入时可继续或明确结束；不能补算未答题。

### 3.2 首页：继续上次 / 地图 / 复习

“继续上次”卡片显示教材、概念、模式、上次位置和是否有待恢复草稿。点击后恢复同一活动而非生成一份新对话；已经完成的上次活动可打开收尾记录，并明确提供“再学一次”或“开始复习”。首页另有地图和复习入口，不能被长对话历史挤出首屏。

**状态与返回：**首次无记录时以“选择教材，开始学习”替代虚构的上次记录；已有教材可直接去地图。无待复习项时显示“当前没有待复习项目”，仍可自选。恢复失败时保留旧记录入口与教材库入口；内容变更先说明兼容情况。断网仍可打开本地卡片和材料；云端不可用仅影响需要它的动作。首页摘要不出现掌握百分比或班级排名。

### 3.3 教材库：基准复用、导入与待核实候选

教材卡片显示书名、年级册次、学科、版本与当前材料状态。版本核实、内容覆盖、审校方式、材料是否在本机是不同信息；“有文件”不能代替“已审校”。

1. 学生可选择已存在的匹配基准，查看简明版本依据后设为当前教材；已审校包直接复用，不要求每人重新审校全书。
2. 接入新材料时先选择本地文件，显示选中文件的非敏感基本信息，再执行导入。若步骤会上传材料进行解析，必须在实际发送前明确说明范围，不默认上传整本。
3. 运行状态至少区分读取、提取、版本匹配、候选生成、检查/整理和完成；只展示真实发生的阶段，可取消。
4. 匹配已核实版本时显示匹配依据与复用包版本。文件不同但可能同教材时展示差异，不只凭文件名确定。
5. 未匹配、目录不完整或版本无法辨认时进入“自动候选 · 未核实”。展示可用部分及问题，允许学生回到基准或显式试用候选；不得由学生点一个确认按钮就变成专家审核或全册基准。
6. 完成导入后可查看材料、目录和审校详情，再去地图。只有达到[产品契约](01-product-contract.md)全册覆盖门槛才能显示全册就绪。

**状态与返回：**取消文件选择不创建教材；重复导入提示已存在及差异，避免悄悄覆盖。文件受保护、损坏、无可读内容、磁盘不可写或读取权限不足时说明具体影响，保留原基准。OCR 不确定、页码映射冲突、缺目录或检查未解决时保留待核实标记。断网可进行已具备的本地步骤；需要云服务的步骤明确暂停，不承诺所有解析均离线。取消保留可用的已保存阶段和来源信息，但部分产物不能标“导入成功”。重新打开时显示实际已完成阶段；不能保证续跑的阶段说明需重做。

审校详情使用“首次 AI 静态检查（非专家审核）”等真实名称，显示范围、问题及可查依据，不使用笼统“审核通过”遮盖方式。待审核是内容状态，不能混进学生理解状态。

### 3.4 地图：目录定位、局部关系与自由进入

1. 打开当前教材地图，默认展开当前或上次所在章的目录与局部概念图；没有上次位置时从真实目录选择章，不能猜一个不存在的首章。
2. 目录树按册、单元、章、节等实际层级呈现，不强行套固定层数。选择条目只改变浏览范围，不自动完成学习。
3. 图显示本章概念、当前选择及有依据的先修/相关关系。图例区分方向、类型与状态；跨章节点以可展开的关系提示出现，不一次铺满全册。
4. 选中概念，在详情区看概念名称、出处、材料状态和三轴摘要。学习进程、理解证据、复习历史/待复习/进行情况各有文字标签，自评另列。
5. 可选“开始学习”“开始复习”“查看证据”“查看出处”。存在建议先修时显示原因与“先看看 / 直接学习”，不锁住目标。
6. 搜索返回概念及其教材位置；跨章命中可直接定位，返回搜索时保留关键词和结果位置。

**状态与返回：**无材料提示去教材库；过滤无结果显示清除筛选入口。关系尚无依据时显示“暂未建立关系”，保留目录与概念列表，不合成依赖。候选地图持续标识未核实；具体不可用概念说明原因。绘图失败或图形操作困难时可用目录/列表和关系文字表完成选择、学习与作答，不阻塞主流程。断网可看本地地图与状态；状态保存失败单独提醒。

### 3.5 工作区·学习：材料 → 尝试 → 帮助/反馈 → 再尝试 → 收尾

**入口：**来自地图、首页恢复或记录中的新活动；顶端明确“学习”、教材、概念和返回入口。仅浏览材料不自动把学习活动置为完成。

1. 进入概念后展示学习目标、可用材料及可尝试的任务。以材料为主，先帮助学生知道在看什么；不默认铺满聊天历史。
2. 学生可先读材料、回答一个与概念相符的问题，或直接要解释。文字、选择、结构图标注和关系题按概念适配，不要求每个概念机械走同一套题。
3. 系统根据回答具体指出已说清的部分、误解和仍缺依据的部分，关联出处。回答明确正确时可确认；概念错误时可直接纠正，不为坚持反问而让错误悬置。
4. “给我提示”“解释一下”“看个示范”“跳过这题”始终可发现；相同意图也支持文字输入。提示由轻到重，学生明确求解释或已困住时转讲解，不强迫再猜。
5. 解释或示范后可邀请学生用自己的话、不同例子或结构关系再尝试。愿意才继续；看过示范的当前同题回答不能包装为独立掌握证据。
6. 学生可上传已有作答图片进入图片反馈流程，或用文字替代；不要求为证明学习而提交个人照片。
7. 点击结束本轮，显示实际做过的活动、可回看的证据、仍需巩固的点及下一步选择。学生自评可选填，单独展示。
8. 达到当前学习活动的可观察完成要求后，学习进程可为“本轮已完成”；若仅提前结束会话或跳过未完成活动，记录结束/跳过事实，不能伪造活动完成。理解状态仍按证据显示“尚无足够证据 / 需巩固 / 初步理解 / 表现稳定”。回地图、看记录、复习或继续相关概念均可，不以完成状态锁住下一步。

**状态与返回：**题目或材料缺失时说明可用部分，不自动临时编造并算正式题。待反馈时保留原始作答、可取消；云端失败不把作答标错。已保存草稿支持返回地图或打开出处后原位恢复。未完成活动返回后保持进行中；“退出页面”“跳过题目”“结束本轮”是不同动作。切换概念、教材或模式先保存当前上下文，新活动不覆盖旧活动。

### 3.6 图片反馈：识别与批改分步确认

1. 学生从本地选择图片，看到预览、删除/重选入口及所属概念或题目；选择本身不等于发送。明确是否会通过云服务识别或批改，学生确认后发送。
2. 图中题干、答案或结构标注无法完整识别时，展示已识别部分与不确定处，用文字“这里看不清/可能识别有误”说明，不凭编造的置信分数造成确定感。
3. 学生可确认或改正识别文字、补充题干、重新拍清楚后上传，或直接改用文字作答。原图、识别结果与学生修订是不同记录。
4. 对足够明确的输入给出反馈，说明针对哪一部分、为什么、如何改；无法确定的部分保留待确认，不整张图一口判错。
5. 只有明确对应到概念且足以评价的作答进入理解证据；未确认识别不强行形成稳定结论。系统识别错误纠正后，原有错误评价应撤销或标失效并重新判断，保留原因。

**状态与返回：**格式不支持、文件过大或无法解码时，在读取后显示实际限制与可用替代路径，具体阈值由实现可验证能力决定，不臆定。图片取消或联网失败后可看本地已保存预览和草稿；不自动重传。切到文字保留已确认的识别内容，不能把图形标注丢失后当作等价完整答案。

### 3.7 工作区·复习：选择范围 → 回忆 → 有依据反馈 → 收尾

1. 首页复习入口或地图“复习”打开范围选择，显示待复习概念、推荐理由、最近复习与可用活动；学生可调整范围或自选其他概念。
2. 开始后进入复习模式，默认先给回忆或应用任务；材料入口仍可打开，打开帮助要如实记录，不用禁用材料制造测试感。
3. 作答后根据实际回答给反馈。发现误解可解释、示范或转一段学习活动；学生也可跳过或结束，不能反复惩罚式出题。
4. 本次收尾展示已作答、跳过、未完成与需巩固的概念，区分活动执行结果与理解判断。已完成复习可以仍显示“需巩固”。
5. 持久化最近完成时间、待复习安排、进行中的会话及最近结果。曾复习过与当前又待复习可以同时显示；跳过单题不伪造该概念的复习完成时间。
6. 返回地图或记录可追溯本次证据及判断变化。后续冲突允许“表现稳定”回落，说明“这次回答显示……，建议再确认”，不抹去历史。

**状态与返回：**无推荐项可自选；自选范围无可用活动时说明原因并可换范围、查看材料，不显示“全部已掌握”。中断保存当前会话，继续上次恢复题目位置和草稿；明确结束部分复习时保留部分结果，未覆盖概念仍未完成。离线可回忆作答并存草稿；只有实际可用的既有反馈或本地判定才能显示结果，不能用假模型回话补齐。

### 3.8 记录与证据详情：知道为什么变化

记录按教材、概念、模式和时间可筛选，区分学习活动、复习活动、理解证据、自评与已学范围自述。摘要可出现“本轮已完成，但仍需巩固”，不能只给一个泛化完成勾。

打开某条证据可见对应任务、原始回答、提示/解释/示范使用、图片识别及修订状态、反馈理由、内容版本和当时判断。状态变化有前后值与原因；同一概念的新旧证据冲突时两者均可回查。学生可提出“这里判断不对”并补充作答，形成新证据或待重评事项，不直接手改为“已掌握”。

**状态与返回：**无记录时去地图；筛选空时可清除。历史内容无法打开时保留文字及版本信息，不自动把旧证据搬到新概念。恢复未完成活动走同一会话；已完成活动的“再学/再复习”建立新一轮。断网可看已落盘材料与记录。记录缺失、局部损坏或保存失败要如实提示影响，不将其解释为学生没学过。

### 3.9 出处与阅读：看完回到原题

从概念、图示或反馈的出处进入，展示教材版本、印刷页与 PDF 页序、对应概念和材料状态。若本机有原材料且允许读取，定位至实际页面；无正文时显示准确位置与对照纸质课本提示，不能展示合成原句。教学示意图需标“示意”，与原教材图分开。

打开出处不提交作答、不改变理解判断；关闭或返回后恢复原活动、输入草稿、材料滚动位置和焦点。定位越界、文件丢失、页码未核实或图片加载失败时保留出处信息并可重新关联材料；不能跳到另一页后假称定位成功。候选材料的待核实标记在阅读时继续可见。

## 4. 主旅程及其结束条件

这些是后续产品走查旅程，不是实现任务卡；章节与概念以真实 inventory 中的项目为准，不能用本文件例子补全未知教材目录。

| 旅程 | 路径 | 应观察到的结束条件 | 需求关联 |
|---|---|---|---|
| J01 首次使用 | 身份 → 匹配教材 → 自选已学范围 → 短诊断或跳过 → 地图 | 自述与诊断证据分开，未测保持尚无足够证据，能自由进入概念 | R02、R08、R09、R14 |
| J02 一次概念学习 | 首页/地图 → 学习工作区 → 阅读 → 尝试 → 帮助/反馈 → 收尾 → 地图 | 活动可结束，三轴状态可分别解释，出处与作答可回查 | R03、R05、R06、R08、R09、R13 |
| J03 求解释与跳过 | 学习中明确要解释 → 示例/讲解 → 可选再尝试 → 跳过或结束 | 没有无限反问；帮助不充作独立证据，跳过不判错 | R06、R08、R17 |
| J04 图片不确定 | 选择图片 → 确认发送 → 查看识别 → 修订/改文字 → 反馈 | 不确定处被说明，修正后可重评，不形成错误的稳定证据 | R10、R11、R17 |
| J05 一次复习 | 首页 → 看理由并调整范围 → 复习作答 → 收尾 → 记录 | 本次活动结果与理解状态分开，历史已复习与当前待复习可并存 | R07、R08、R09 |
| J06 中断恢复 | 活动输入 → 返回地图/首页 → 继续上次 → 关闭重开 → 继续 | 恢复同一活动与已保存草稿，无重复记答，无跨版本误套 | R01、R12、R15、R17 |
| J07 导入候选 | 教材库 → 未知教材导入 → 待核实 → 预览 → 返回基准 | 候选标识持续可见，不覆盖基准、不冒认全册已核实 | R02、R03、R04、R16 |
| J08 断网与失败 | 活动输入 → 请求失败/取消 → 本地查看 → 学生主动重试 | 作答未丢、不误判、状态真实，迟到响应不污染后续活动 | R01、R14、R15、R17 |
| J09 全册导航 | 按真实目录逐章对账 → 概念入口 → 查材料/活动/出处/关系 | 无不可解释缺口，内容覆盖报告对应冻结分母；首节成功不代替全册 | R03、R04、R05、R18 |

## 5. 返回、持久化与活动边界

| 离开方式 | 返回时必须保留 | 状态边界 |
|---|---|---|
| 打开出处后返回 | 原活动、题目、已输入内容、材料位置与焦点 | 查看出处不自动提交或完成 |
| 工作区回地图再进来 | 选中概念、地图范围、模式、同一活动及草稿 | 地图浏览不改学习进程和理解 |
| 搜索结果进工作区再返回 | 搜索词、筛选和原结果位置 | 不因新搜索创建学习活动 |
| 切换模式/概念/教材 | 原活动与草稿独立保存，新上下文显式显示 | 不覆盖旧证据，不把旧教材判断直接套给新版本 |
| 返回首页后继续 | 上次活动准确位置、待反馈/已取消/已保存状态 | 继续同一活动，不自动重发云请求 |
| 关闭重开 | 学生记录范围、教材、会话、原始作答、证据、自评、复习字段 | 只承诺已成功保存部分，失败或未保存须明确告知 |
| 内容包更新后打开历史 | 原内容版本和原始证据，可查变化原因 | 受影响结论待重新确认；无法映射则保持历史，不静默迁移 |
| 模型账号切换、退出或服务授权失效 | 本地学习身份、原活动与已保存记录 | 模型退登不删除学情，换模型账号不迁移或覆盖学情；不自动续发请求 |

输入自动保存与正式提交区分：草稿不是证据；提交后原始作答不可被下一次修改覆盖。重试只重做失败阶段，不创建重复作答或重复活动完成记录。记录和活动必须在同一身份、教材版本、概念及会话上下文内恢复，具体一致性机制由[数据契约](05-data-contracts.md)与[系统设计](06-system-design.md)规定。

## 6. 教学行为边界与学生可控权

- 引导优先：先帮助学生表达想法、观察材料和说明理由，但不把每一轮都写成问题。学生明确要求解释、示范或确认时应响应。
- 正确与错误都具体：可以确认正确回答并说明依据；对错误概念直接指出哪部分有问题，再给适量解释或邀请修正。不能附和错误，也不能只说“再想想”。
- 帮助可控：提示、解释、示范、跳过、结束都有明确动作；不以羞辱、连续追问、连胜奖励或学习锁促使学生坚持。
- 证据适度：反馈评价这次作答，不给学生贴能力或人格标签；一次答错、一次答对、一次跳过均不能推断整体水平。
- 模型不确定与材料未核实要分别说明；未知出处不编造，超出当前材料的解释标出边界，不能假称教材结论。
- 图与图片服务理解：不把画得漂亮当作理解，不把字迹或识别失败当作概念错误；有语义等价的文字作答路径。
- 自评是学生观点：可选填、可修订，与系统证据并列；不同意见保留，不用强制学生改自评来配合系统。
- 不宣称教学实证：产品里的“表现稳定”是有限证据下的当前判断，不是学习实验结论、标准化成绩或永久掌握认证。

## 7. 键盘、文字替代与辅助使用

所有主旅程支持键盘完成。Tab 顺序与阅读顺序一致，焦点可见；按钮用 Enter/Space 激活；对话框打开后有明确焦点与关闭入口，关闭返回原触发处。Escape 可关闭浮层，不能默默丢弃未保存内容。发送动作有明确按钮与快捷键说明，多行文字换行不意外提交。

| 图形或指针动作 | 必须具备的文字/键盘替代 |
|---|---|
| 展开目录与选择概念 | 可聚焦树或层级列表，按键展开/收起并进入详情；同时提供可搜索列表 |
| 图中查看先修/相关 | 关系表列出起点、关系类型、终点、方向及理由；不只依赖线色和箭头 |
| 结构图拖拽标注 | 带编号部位列表，为每个部位选择或输入名称；能重新编辑，形成同等语义答案 |
| 关系连线题 | 起点、关系、终点的文字表单，必要时选择方向；不得因使用替代路径降低评价 |
| 拖入图片 | 可聚焦的“选择图片”按钮与原生选择入口，上传后能移除/重选；可改文字 |
| 图形缩放与平移 | 明确的缩放、适配和重置按钮，且列表路径完成同一概念选择；不要求触控板手势 |
| 看颜色/悬停获知状态 | 同时有文字标签与可聚焦详情；错误、状态和核实程度不只靠颜色或悬停 |

图形与文字答案相互切换保留已有语义；无法无损切换时先说明并保留原答案，不能静默清空。图示有简短替代说明；题目中的必要结构可通过编号列表或文字关系表达。文字放大、系统高对比与键盘操作仍能看到提交、取消和返回入口，不因布局截断而无法完成活动。

## 8. 布局与可读性约束

- 首页首屏优先展示继续上次、地图、复习，当前教材和服务状态简短可查；不设置班级、教师、终端或开发控制台卡片。
- 教材库优先呈现当前教材、版本及核实状态，再呈现导入；审校细节可展开，但未核实标识不能折叠到不可见。
- 地图采用目录定位区、章级局部图/列表、概念详情的语义分区。空间不足时分区可折叠或切换，保留当前选择；全册缩略概览不能替代可用的局部导航。
- 工作区的主要区域是材料与当前活动，解释/对话作为辅助区，可收起。目标、题目与输入不能被长消息推到屏幕之外；材料与对话可各自滚动，当前输入和提交区域始终可到达。
- 适应普通 Windows 窗口、最大化、窄窗及系统缩放；不写死只适用于特定分辨率的三栏。窄窗优先保留当前材料/题目与操作，其他区切换可达且状态不丢。
- 反馈先说具体结论、依据和下一步，长解释可展开；出处紧邻相关内容。不把工具轨迹、内部错误或模型参数塞入学生阅读区域。
- 进展页用三个数字（学过 / 要再练 / 待复习）加按日期的时间线；展开可看证据与出处，自评独立。可显示真实计数，但不造掌握百分比、综合战力或排名。
- 本文不固定品牌视觉、组件库、图形引擎或精确像素值。后续应以主旅程可完成、材料可读、状态可分辨及键盘等价路径作为布局验收依据。

以上流程只有在实际运行、覆盖对账及边界验证后才能标为通过；验证类型与局限应写入[验收方案](07-acceptance.md)要求的记录。当前缺少原始教材 PDF 的事实不改变全册目标，详见[产品契约](01-product-contract.md)；不能让自有测试材料或首节走通替代全册就绪。
