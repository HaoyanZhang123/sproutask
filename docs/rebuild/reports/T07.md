## 实现与范围

新增独立包 `@edu/tutor`（`education/packages/tutor/`，`type: module`，唯一 public entry `src/index.ts`；运行期依赖仅 workspace `@edu/domain`、`@edu/knowledge`、`@edu/learner`，无第三方运行期依赖）与生物 Skill 目录 `education/skills/biology/`。未改其他包、`education/package.json`、`pnpm-workspace.yaml`、`contract-lock.json`、旧工程或原 DSH 安装。

1. **教学编排服务**（`src/tutor-service.ts` + `src/pedagogy.ts` + `src/context.ts`）
   - learn/review 两模式；`startSession` 绑定内容、学习者与模型网关；`submitTurn` 是唯一教学入口。
   - 策略可解释且确定性：引导提问 → 提示 → 分层解释/例子 → 分步示范 → 明确纠错；**学生主动要提示/解释/例子/示范/答案时直接提供**，不机械拒答。答案或完整步骤标记 `disclosure`，并把 `answer/worked_solution/explanation` 写入下一次作答的 `helpUsed`，由 T06 规则判为 assisted/非独立证据。
   - 连续 2 次未解决失败（`escalateAfterFailures=2`）→ `worked_example` + `difficulty=reduced` + 表征切换（step_by_step），不再继续反问；引导提问有 `maxConsecutiveProbes=2` 上限。
   - 复习模式：先回忆（recall）→ 按作答走辨析（discriminate）/迁移（transfer）/补前置（prerequisite），复习完成与理解判断分开（`finishReview` 交给 T06 `completeReview`，不自动升级理解）。
   - 跳过/终止/取消/超时：`skip`/`end` 走 `endSession`（abandoned/completed 明确），不伪造完成、不判错；`signal` 取消在模型返回前后都检查，迟到响应不提交判定；`timeoutMs` 超时返回 TIMEOUT 且保留已存作答。
   - 流式事件与最终状态分离：返回 `events`（`turn.started`/`phase`/`model.delta`/`tool.requested`/`tool.result`/`pedagogy.decision`/`turn.completed`，只含展示进度）与 `state`（权威最终状态）两个字段；测试断言事件中不含 `progress/state/consecutiveFailures` 等权威投影。
2. **上下文构建**（`src/context.ts`）：只带当前概念材料、最多 2 个直接前置概念、必要证据摘要（不含学生原文）、当前活动与学生本轮输入；所有内容块 `trust=untrusted_data`（教材/图片文字/学生输入/历史记录都当数据），系统指令只来自 Skill 且不授工具权限。
3. **教育工具 factory**（`src/tools.ts`，6 个工具，唯一 allowlist）：`edu_get_concept`、`edu_resolve_source`、`edu_list_activities`、`edu_submit_attempt`、`edu_get_feedback_rubric`、`edu_progress_summary`。每个工具：封闭 JSON Schema 运行时校验（未知字段拒绝）、宿主绑定 `learnerId`/`packKey`（模型参数不能覆盖）、幂等键（重复调用返回首次结果）、`CancellationToken`+`timeoutMs`、结构化错误 `AUTH/QUOTA/UNSUPPORTED/NETWORK/CANCELLED/TIMEOUT/INVALID_INPUT/UNKNOWN_TOOL/...`；`unknown tool: <name>` 为白名单外统一错误，危险名（bash/shell/read_file/run_code/http_request/install_plugin…）额外 `permission.denied` 审计。工具定义是普通数据对象（`parameters/output.schema/output.render/execute`），不 import dsh-tools，交给 T13 `ctx.tools.register`。

## 失败与返工

开发轮问题均在本卡 scope 内修复，未删测试、未放宽判据：

1. **首轮 typecheck 失败（10 errors）**：`roundIndependence` 误从 `@edu/domain` 导入（实际在 `@edu/learner`）、`TutorGradeRequest` 缺 `sessionId`、`roundIndependence` 签名、工具 schema 缺 `required: []`、`TutorErrorCode` 缺 `CONTRACT_REJECTED`、`TutorProgressExplanation.evidence` 类型不匹配。逐项修复后 typecheck 0。
2. **首轮 test 3 失败**：
   - S04 第一处错答被判 `explicit_correction`：`summarizeGrade` 把“rubric 有 not_met”当成 core misconception；改为只有模型语义信号 `coreMisconception` 才判核心误解（一般错答先 hint）。复跑通过。
   - S02 仍判 hint：`summary` 在模型语义信号到达前用默认信号生成；改为在 `emitModelAndDecide` 收到 `signals` 后再由 `summarizeGrade(grade, signals)` 生成 summary，service 用该 summary 决策/计数。
   - 工具重复调用 idempotency 断言位置错误（检查 value 内字段而非 outcome 的 `duplicate`）；修正测试断言，行为本身已正确（learner 只 1 次 submit/record）。
