## 失败与返工

1. **仓库 `.env` 阻止启动**：在仓库根 cwd 运行 `dsh web --help` 时，DSH 启动器读取 `E:\DSH\workspaces\ai4edu\.env` 并因 bootstrap-only 变量 `DEEPSEEK_BASE_URL` 直接退出（exit 1）。**我没有打开、复制或记录该文件内容**，只看到启动器报出的变量名。处理：所有后续命令 cwd 固定到 `education/.local/cache/T00/probe-work`（无 `.env`），并在 runner 中删除继承的 `DEEPSEEK_*`/`DSH_*` 变量。这也是未来打包/启动必须带独立工作目录的原因。
2. **`$home` 只读变量 → 误写用户目录**：见“实现与范围”的申报；已删除并留证。
3. **pnpm 退出码 1**：`ERR_PNPM_IGNORED_BUILDS`（`dsh-subprocess-local`、`@google/genai`、`koffi`、`node-pty`、`protobufjs` 的构建脚本被 pnpm 默认拦截）。node_modules 已完整安装，探针不需要这些原生构建；**没有**为此放宽 `onlyBuiltDependencies`。
4. **profile YAML 解析失败**：未加引号的 persona 文本含 `: `，YAML 报错；改为单引号字符串后通过（错误本身证明 profile 加载是真实解析而非跳过）。
5. **`INVALID_MODEL_INFO`**：mock adapter 的 `resolveModel` 初版缺 `id/name/context`；按 `normalizeModelInfo` 要求改为 `{provider,id,name,context:{contextWindow}}` 后通过。
6. **根替换首轮失败**：仅禁用 `ui-layout` 时，23 个客户端条目 pending（等待 `layout`/`uiWorkspace`/`uiConversation` 等服务），shell 显示 “Failed to load plugins”。按 04 文档“独立 root 不能假定默认 sidebar/main/rightbar”处理：同时禁用只服务默认布局的条目，第二轮剩 7 个 pending（`configForms`/`resources`），补回 `ui-settings`（configForms 提供者）与 `resources`、去掉 `directory-picker` 后渲染成功。
7. **Chrome `--screenshot` 挂起**：页面持有长连接，`--virtual-time-budget`/`--timeout` 不退出；改用 CDP（Node 内置 `fetch`+`WebSocket`）控制：`Page.navigate` → 轮询 DOM → `Page.captureScreenshot`，稳定退出。
8. **`--patch` 负向对照参数被 PowerShell 折叠成单字符串**：改为独立的 `edu-web-duplicate` profile（可复现，不依赖 shell 引号技巧）。
