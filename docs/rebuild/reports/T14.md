口径与限制（逐条都写进了 JSON 的 `caveat` 字段）：

- 第 3、6、8 条有"引线标签被裁剪带切掉"的副作用（细胞核、果皮和种皮后半、青霉左侧标签），**判定只针对图注与画面主体**，不等于标注完整性核对通过。
- 第 7 条的"无法判断"是工具限制：T03 只登记了图注文字框（`captionBbox`），没有登记图主体外接框，裁剪无法定向。要判定这一条，需要放大裁剪带再跑 1 次视觉调用（本轮预算不允许）。
- 耗时是"本次调用发起 → 下次调用发起"的时间戳间隔，包含上一回合判定文本的输出与工具往返，**不是纯 API 延迟**；会话内看不到计费账单，费用只能按图像像素估算视觉 token（≈像素/750），表里给的是这个估算值，不是账单。
- 模型对"一致"的判断偏宽（只判"对象存在且文字与画面不矛盾"），**不判**"这幅图在教学中是否合适、示意是否有科学性错误"。
