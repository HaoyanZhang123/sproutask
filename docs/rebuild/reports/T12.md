   - 图片模式下渲染真实 `<input type="file" accept="image/png,image/jpeg">`，配“拍照 / 选择图片”文案（`label` 与 input 关联，键盘可聚焦/触发）；文件读取后显示文件名、像素、MIME、KB。
   - 选择 ≠ 发送：选中文件后只在本机生成 `data:` 预览；必须先点“预览图片”，再点“确认发送给模型识别”。没有图片或未预览时确认按钮 `disabled`，并给出禁用原因 title。
   - 提供“重新选择 / 重新上传”“取消本次作答”“取消等待”；取消等待用 generation token 丢弃迟到回调，不会自动重发。
   - 文件类型/大小错误、服务错误均为中文 `role="alert"`；限制 PNG/JPEG 且 ≤5 MB，超限提示压缩/重拍/改用文字。
   - 发送时携带 `sessionId`、`activityId`、`assetId`、`base64`、`mime`、`width`、`height`，走 `StudyDataSource.submitImageAnswer` → 运行时 `/edu/api/g1/image`。
2. **结果展示**：图片结果区显示质量门澄清（模糊/倾斜/空白逐条理由、不会判错、只记待澄清）、要点（已达成/未达成/待确认）、不确定项、出处、`graderVersion`；右侧 `mountFeedbackView` 仍显示完整反馈。澄清结果明确写“只记为待澄清（draft/pending），不会写入成绩”。
3. **判分落库与幂等**（`education/runtime/src/g1-service.ts`、`host-plugin/src/index.ts`、`client-plugin/src/live-sources.ts`）：
   - `imageQuality` 先解析/创建学习会话，构造真实 `ActivityAttempt`（`inputType=image`），调用 `learner.submitAttempt` 写 `attempt.submitted`；质量门通过后调用 `guardEvidence` + `learner.recordGradedAttempt` 写 `assessment.committed`。
   - `attemptOutcome` 不再为 null：正常判分、质量门澄清、重复提交都返回持久化结果；澄清路径只写 attempt/pending，`assessmentCommitted=false`。
   - 幂等键：`attemptId = attempt.image.<sha256(sessionId|activityId|imageSha)[0..32]>`，`requestId = request.image.<同一 digest>`；同一图片重提交命中既有 attempt，不二次调用模型、不新增 journal 行。
   - 跨进程重复提交无进程内缓存时，从 `assessment.committed` 重建只读展示用 grade（不再调用模型、不再写成绩）。
   - 修正 `journalSessions` 读取窗口：原来 `readFrom(..., 0, 2000)` 超过 storage 的 1000 上限会静默拿不到会话，导致每次图片请求新建 session、幂等键失效；改为按最近 1000 条读取。
   - 为让真实手机图片能通过宿主 body 上限，图片路由单独放宽到 12 MiB（路由仍拒绝 >8 MiB base64）。
4. **测试**（本轮新增/改写）：
