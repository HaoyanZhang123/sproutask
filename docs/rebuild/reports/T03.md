## 实现与范围

新增 `education/packages/importer/`（唯一 public entry `src/index.ts`，`@edu/importer`，`type: module`，**运行期第三方依赖 0**，仅 Node 内建 + Windows 系统组件）。模块与职责：

1. **受管资产与 PDF 校验**（`src/assets.ts`、`src/pdf/document.ts`）：
   - 只接受 `ManagedFileHandle`（`assetId` 必须过 domain 的托管句柄校验，形如路径的 handle 直接 `ASSET_HANDLE_INVALID`）；路径由宿主 `ManagedAssetStore` 解析，`realpath` 后必须位于显式允许根内（`ASSET_PATH_OUTSIDE_ROOT`）。
   - 本地重算 SHA-256（`ASSET_HASH_MISMATCH`）；PDF 头/交叉引用/页树解析失败→`PDF_CORRUPT`；trailer 含 `/Encrypt`→`PDF_ENCRYPTED`；0 页→`PDF_NO_PAGES`；确认页数不符→`ASSET_METADATA_MISMATCH`。所有失败都以 `{code,message,retryable}` 返回，**不抛裸异常**。
   - 零依赖 PDF 读取器：经典 xref 表、xref stream、对象流（ObjStm）、FlateDecode/ASCIIHex/ASCII85、PNG/TIFF predictor、损坏 xref 的全文件恢复（`recoveredXref`）。
2. **文本层优先 + 扫描页 OCR**（`src/pdf/text.ts`、`src/engines/*`）：
   - 文本层路径解析内容流 `Tf/Td/TD/Tm/T*/Tj/TJ/'/"`，支持 `/ToUnicode` CMap（bfchar/bfrange/codespace）、`/Differences`、WinAnsi；字体/CID 不可解码→显式 `FONT_ENCODING_UNSUPPORTED`（不伪造空页），无文本→`EMPTY_TEXT_LAYER`，之后才进 OCR。
   - OCR 走 Windows 系统组件：`src/engines/scripts/winrt-ocr.ps1`（`Windows.Data.Pdf` 渲染 + `Windows.Media.Ocr` 识别，按批 `-Manifest` JSON 驱动，逐页写 JSON；本机只有 Windows PowerShell 5.1，脚本按 5.1 兼容、纯 ASCII）；`WindowsOcrPort` 负责可用性探测、批次超时、取消时杀进程、把逐页结果映射为带像素 bbox 的 `OcrPage`；测试用 `FakeOcrPort`（可注入页级失败/延迟/取消后迟到），**不依赖 40 MB 教材即可跑 OCR 管线**。
3. **页/印刷页分离、bbox 与图文结构**（`src/structure/*`、`src/import/service.ts`）：
   - `SourceRef.pdfPage`（1 基 PDF 页）与 `printedPage`（页脚/页眉标签，string|null）分开保存；无标签一律 `null`，**不推算偏移**。图注定位用归一化 bbox（OCR 行由像素坐标归一化；文本层由文本矩阵估算）。
   - 文本层按字号/行距/栏位合并段落并分类 heading/paragraph/list/caption；OCR 每行一个 block；页脚页码与顶部装饰噪声分别记为印刷页证据与 `HEADER_ARTIFACT_DROPPED`（**计数保留、不进正文**）。
   - 扫描页整页图落为受管资产（`Figure.originalAssetId`，内容哈希去重），图注行 bbox 作为来源区域；**图形区域的 CV 裁切明确降级为“整页图 + 图注位置”**（见未测项）。
   - 机器清洗只写 `revisedText` + `revisions.jsonl` 账本（原稿 `originalText` 不可覆盖）；OCR block `reviewState=candidate`、文本层 `machine_checked`，`SourceRef.verification=unverified`。
   - 目录候选：只“提出”目录页与条目（`toc-candidates.json`），条目的 `pdfPage` 保持 `null`，印刷页码以书页原样保存。
4. **checkpoint / 缓存 / 取消语义**（`src/import/storage.ts`、`src/import/service.ts`）：
   - 缓存键 `(sha256, parserVersion, page)`；任务页文件、事件流 `events.jsonl`、迟到结果记录 `rejected-late-results.jsonl` 分目录落盘，原子替换写入。
   - `cancel` 之后运行中的页结果一律不发布（写 `rejected-late-results.jsonl`，不进缓存/产物）；`resume` 幂等（确定性 ID + 缓存命中，二次 resume 产物字节一致）；`retry` 只重跑指定页，**带修订的页明确跳过**并回报 `skippedPagesWithRevisions`。
   - 同 hash 命中→返回既有 job（不重复建书）；同版不同扫描需重建页码映射；同名异版不自动绑定（`src/matching.ts` 三态；页数不同即视为不同印次）。
5. **失败可见 / 离线**（`src/errors.ts`、`src/import/service.ts`）：27 个稳定错误码 + 学生向中文文案 + retryable；无网络时本地 identify/extract/structure 全部继续，概念抽取以 `CLOUD_EXTRACTION_PAUSED` 暂停（stage=structure、status=paused），不伪装完成；无 OCR 引擎/语言包以 `OCR_ENGINE_UNAVAILABLE`/`OCR_LANGUAGE_UNAVAILABLE` 失败并保留已完成页；磁盘满（ENOSPC/EDQUOT）→`STORAGE_FULL` 且不发布产物。
6. **引擎/许可/T16 物料**（`src/materials.ts`）：机器可读清单（WinRT 组件、中文 OCR 语言包、Windows PowerShell 5.1、Node 内建、随包脚本、显式“非依赖”Tesseract/Ghostscript/Poppler/Python），含检测命令与可再分发结论。
7. **真实教材基线 CLI**（`src/cli/ocr-baseline.ts` + `bin/ts-js-resolve.mjs`）：用本包（不是一次性脚本）跑真实 PDF，产出 `baseline-summary.json`/`baseline-pages.tsv`/`baseline.log` 与任务产物；`node --import ./bin/ts-js-resolve.mjs` 让 TS 源码零构建直接运行（包内 `.js` import 说明符由 loader hook 映射到 `.ts`，避免额外构建依赖）。
