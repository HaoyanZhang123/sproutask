## 2. sharp 验证（决定能否裁）

### 2.1 方法

- 隔离测试树：`education/.local/cache/T16/crop-test`（hoisted 527.8 MB 复制后删除 `sharp`、`@img`、`libreoffice-kit`、`sherpa-onnx`、`node-pty`，保留 `dsh-attachment-local`/`dsh-subprocess-local`）。
- 启动 DSH web（隔离 `DSH_HOME`、`EDU_DATA_ROOT`、`--no-open`、无 Key），检查 `/edu/api/status` 和 Edge 渲染。
- 附件/缩略图路径：直接调用 DSH `@deepseek-ai/dsh-attachment-local` 导出的 `prepareImageFile`（`SaveImageAttachment` + 默认 limits/policy），输入 T11 合成图 `01-clear-correct.png`（24,318 B，900×600），不调模型。
- 对照：同一图在完整 hoisted 树（含 sharp）上跑同一函数。

### 2.2 结果

| 场景 | 启动/status | `prepareImageFile` |
|---|---|---|
| 含 sharp（`hoisted-test`） | 正常 | **OK**：24,318 B，`image/png`，900×600，attachmentId `sha256:b774bd15cf7a27a88bbb802dd9f608945615303f424855320bab9dd5185a7d22` |
| 去 sharp（`crop-test` / 最终 payload `app/`） | 正常，status 200 | **失败**：`Error MODULE_NOT_FOUND: Cannot find module 'sharp'`，Require stack 指向 `dsh-attachment-local/lib/index.js` |

证据：`run.../sharp/with-sharp.json`、`run.../sharp/without-sharp.json`；原始启动见 `run.../cold-start/`。

### 2.3 结论

- `sharp` 只在**图片 raster admission/归一化/缩略图**时被 lazy require；不启动 DSH 时不需要它，所以 **web 启动/教育 root 可裁**。
- 但一旦走 **DSH 原生图片附件/上传**，`sharp` 是硬依赖；去掉后图片路径报 `MODULE_NOT_FOUND`，不是可恢复的“降级文字”。
- 因此：
  - **A20 若继续使用 DSH 原生图片上传 → sharp 不可裁**，建议 `--keep-sharp`（+19.8 MB）。
  - **若 A20 改走 T11 教育自有图片管线**（`@edu/visuals` 为纯 JS，`grep` 无 sharp 引用），可裁；但 T13 当前 client 仍是 fixture，图片路由尚未接入，**当前 G3 下 A20 为 BLOCKED**。
- 最终默认 payload 按用户“5A 全裁”决定不含 sharp；构建脚本保留 `--keep-sharp` 供 A3/主控选择。

## 8. 风险 / 未测

- **sharp/A20**：默认 payload 无 sharp，DSH 原生图片上传/缩略图不可用；若 A20 走 DSH 附件，需 `--keep-sharp`（+19.8 MB）或实现 T11 图片路由。
- **裁剪后待验证服务**：去掉 `dsh-subprocess-local`/`dsh-attachment-local` 会触发 7 个 pending（session-controller/file-upload/terminal/schedule 等）；当前保留两者避免 pending。future 若继续裁，需要逐项回归。
- **office/speech/pty 功能**：对应包已移除；学生端若不做 Office/语音/终端则无影响，但需产品确认。
- **首跑慢**：23 s（杀软扫描 34k 文件）；可在安装器里预热/签名/排除目录，但不建议改系统设置。
- **未签名**：launcher/installer 无签名，SmartScreen 会提示未知发布者；A3 需证书。
- **无 Key 输入 UI**：launcher 清空 `DEEPSEEK_API_KEY`；学生如何配 Key 未在 A1 解决。
- **Edge 依赖**：Win10/11 自带；Edge 被卸载/企业策略禁用时需回退默认浏览器。
- **profile 迁移**：`setup-education-home.mjs` 把 payload 绝对路径写入 profile；安装路径固定为 `current/` 时更新安全；若移动 payload 目录，首次启动需重建 profile（当前只在 profile 缺失时重建）。
- **未测**：真实学生机、无 Edge、无 UCRT、Win10 具体版本、SmartScreen 实际弹窗、NSIS 安装/卸载、真实模型调用、PDF 导入/图片 OCR。
- **内容/集成**：内容 2.0.0 仍是 `candidate`（hash `7b5f055c…`），T13 client 仍 `fixtureData=true`；T15/G2 未通过。payload 是“可启动学生包”，不是 G3 学习闭环。
