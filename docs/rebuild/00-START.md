## 1. 用户只需做的一件事

复制[MASTER-PROMPT](MASTER-PROMPT.md)的代码块给具备工具的主对话。主对话先读本包，然后按DAG自主实施、派发、验收、返工并持续推进。若未来只说“阅读了解”，不自动实施；只有用户发送实施提示词/明确实施要求才启动业务改动。

主控开工顺序：00→01目标→03现状→04内核准入→05公共契约→06架构→07验收→08自动调度→tasks/index.json。做UI/教学时读02，交回用09。不要沿旧HANDOFF先重做一轮无关审计或反复问已批准产品方向。
