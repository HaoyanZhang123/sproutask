# T00 — 跨域变更请求

本文件只列 T00 无权自行落地、需要其他 scope owner 处理的事项。T00 未修改任何 `education/` 根配置、公共契约或他人目录。

## R1 → T01：把探针排除在 education workspace 与 Git 之外

- **事实**：`education/probes/runtime/` 是独立 pnpm 项目（自带 `package.json` + `pnpm-lock.yaml`，未使用 `--ignore-workspace` 时也会被上级 workspace 发现）。
- **请求**：
  1. `education/pnpm-workspace.yaml` 的 `packages` 不要包含 `probes/**`；如 T01 采用 workspace，请显式排除。
  2. 在 `education/.gitignore`（T01 拥有）加入 `probes/runtime/node_modules/`、`.local/`（或确认根 `.gitignore` 已覆盖 `education/.local/`）。
  3. 允许探针继续以 `pnpm install --ignore-workspace` 独立安装固定 DSH 版本。
- **理由**：探针需要与被测版本一一对应的独立 lockfile；混入产品 workspace 会污染产品锁文件并让版本升级互相牵制。
- **不影响**：T01 不消费探针源码，只消费 `docs/rebuild/runtime-lock.json`。

## R2 → T01：教育客户端插件的构建配方与根组合约束

- **已证事实**：本版客户端 bundle 协议是 `window.__ModuleLoader__.load({id, factory})`，`dsh.client` 需 `platform:'web'` 与 `exports['./client']` 产物；T00 用**手写静态 bundle** 成功替换默认根并渲染（证据 `30-web/render/page-meta.json`）。
- **缺口**：正式教育 UI 仍需 monorepo `pnpm run build`（tsdown）产物；published 包不含该构建配方。请 T01 在冻结 adapter/组合层时决定：
  1. 教育客户端插件的构建方式（自有 tsdown/vite 配置 vs. 手写 bundle 仅用于脚手架）；
  2. 根组合策略：禁用 `ui-layout` 时必须同时处理依赖 `layout`/`uiWorkspace`/`uiConversation`/`sidebarRight` 的客户端行（本版 23 行 pending），否则 shell 会报 “Failed to load plugins”（证据 `31-web-duplicate` 与首轮失败记录）。
- **约束**：单 `root` slot 只能有一个占用者；重复占用会让`ui-layout` 激活失败并中止挂载（这正是我们要求的“无重复占用”行为）。
