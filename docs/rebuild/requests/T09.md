# T09 变更请求与后继输入

## 1. 生产 API factory（T13 必须）

`@edu/client-library` 只消费注入的 `LibraryDataSource`，不 import `@edu/importer` / `@edu/knowledge` 的私有实现。T13 需要：

- 用真实 `ImportPort` 适配 `chooseFile/startImport/jobStatus/cancelImport/resumeImport/retryImport`；`startImport` 的 `reused`/`match`/`scope`/`coverageStatus` 由 `matchBookIdentity` 与发布规则给出，UI 不自行判定基准。
- 用 `import.progress` 实时通知实现可选的 `watchImport(jobId, listener)`；页面重挂载后能重新订阅（本卡已用 UI 重挂载测试）。
- 用 T04 `ContentQuery.resolveSource` + 受控页图 asset API 适配 `openSource`：只返回 `SourceRef`、PDF 页、印刷页、blocks/figures、`assetId` 与归一化 bbox，不返回路径；真实页图由宿主提供可显示资源（本卡 fixture 是示意占位，不是真实页面）。
- `createRequest` 用组合根的真实 `RequestContext`（宿主绑定 learnerId / clock / requestId）；不要使用 UI 默认测试工厂。
- `returnPath` 由 T12/T13 传入，用于“查看来源后返回原活动”；活动草稿/焦点恢复仍需要 T13 的会话层协作。
