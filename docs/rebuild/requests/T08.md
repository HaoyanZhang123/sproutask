## 7. 模型 API Key 宿主端点（本轮新增请求，host owner）

T08 只实现客户端录入/状态 UI；**当前 runtime 尚无 `/edu/api/auth/key`**，UI 会显式显示“接口未实现”，不假装保存成功。请 host owner 在 runtime 侧实现（T08 不写 runtime）：

- `POST /edu/api/auth/key`
  - 请求：`{ "apiKey": "sk-..." }`（只在请求体；禁止 query/路径/日志）
  - 成功：`200 { "ok": true, "status": "configured" }`，**绝不回 Key**；可选 `maskedSuffix` 只允许 4 位脱敏后缀。
  - 错误：`400/422` 格式、`401/403` 鉴权、`429` 配额、`5xx/网络`；统一 `{ok:false,error:{code,message,retryable,category?}}`。错误 message 不得回显 Key。
- `GET /edu/api/auth/key`
  - 成功：`200 { "ok": true, "status": "configured"|"missing", "maskedSuffix"?: "1234", "lastCheckedAt"?: "..." }`；只允许脱敏后缀，不得回 Key。
  - 用于页面刷新/重启后显示 configured + `****后四位`；不把 Key 写入 localStorage/sessionStorage。
- `DELETE /edu/api/auth/key`
  - 成功：`200 { "ok": true, "status": "missing" }`；清除宿主加密存储后回到本地模式。
- 安全：同源 + DSH token-cookie 鉴权；请求体限长；Key 只进入宿主加密存储，不写日志/快照/URL/客户端存储；`auth.status` 仍只暴露 `available/status/lastCheckedAt`，不因本端点扩展凭据字段。
- 降级：端点 404 时客户端显示“接口未实现：本机宿主尚未提供 /edu/api/auth/key；Key 没有保存”，保存按钮可重试，不进入 configured。
