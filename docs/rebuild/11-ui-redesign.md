# 界面重构（A+B）——方案与实施记录

> 2026-11-04 起实施。目标：把"写给验收和 AI 看"的界面，改成"学生能直接用"的界面；**功能与公共契约不变**。
> 工程状态仍以 [`PROGRESS`](../PROGRESS.md) 为准；本文件记录设计与实施口径。

## 1. 范围

- 做：`education/client/*` 的表现层与文案；`client/shell` 的外壳与页面；学习台、两级知识地图、今天、进展、设置、我的课本。
- 不做：`education/packages/*`（领域/存储/教学）、`runtime/*`（DSH 边界）、内容包、公共契约、任何新依赖。
- 验收口径：A23（教材库/地图/工作区/记录真实可用、1280×800 与 1440×900、键盘可走、无终端/源码/插件市场入口）继续成立。

## 2. 设计方向

一句话：**一屏一件事，用学生的话，有温度。**

| 项 | 决定 |
|---|---|
| 画布 | 暖纸底 `#faf7f0`；卡片白；教材页 `#fdfaf2` |
| 主色 | 深绿 `#2f6b4f`（主按钮、当前项） |
| 次色 | 琥珀 `#a9661f`（要再练 / 待复习）；蓝 `#2f5d8a`（在学） |
| 字号 | 基准 16px；正文 16–18px / 行高 1.85；页面标题 30–32px |
| 形状 | 圆角 12/18/24；轻阴影；8 的倍数留白 |
| 图标 | 内联 SVG，不引图标库 |
| 字体 | 系统字体栈（MiSans / HarmonyOS Sans / 微软雅黑），不加外部字体 |
| 动效 | 150–200ms，尊重 `prefers-reduced-motion` |
| 状态 | 颜色 + 文字 + 形状三重编码，不靠颜色单独表达 |

## 3. 信息架构

| 现在 | 之后 | 路由 |
|---|---|---|
| 首页 | **今天** | `/home` |
| 工作区 | **学习** | `/workspace` |
| 记录 | **进展** | `/records` |
| 地图 | **知识地图**（两级） | `/map` |

## 4. 三屏规格

### 4.1 今天（`/home`）

- 顶部一句问候 + 一条引导；主卡「接着上次」：概念、模式、第几步、草稿状态、`继续上次 / 从头开始`。
- 右栏「今天可以做」四行：复习（到期概念或自选）、去目录挑概念、看进展、我的课本。
- 底部进度条：学过 / 要再练 / 待复习 + “全册 43 个概念”说明 + 查看进展。
- 删除：服务状态三卡、内容覆盖计数解释句、平台账户说明。

### 4.2 学习台（`/workspace`）

- **一张对开学习台**：左页课本（纸色、页码、折叠“容易混淆/出处”），右页练习（题干、整行选项、提交/提示/跳过）。
- 提交后**原地**展开反馈：结论、依据、出处、`下一题 / 再看看材料`；不再出现第二张反馈卡。
- 小芽从右栏降为右下浮起按钮，点开右侧对话层（提示/解释/举例 + 输入）。
- <1100px 单页：课本收进抽屉；对话层占满宽度。
- 保留：草稿恢复、待反馈、图片作答、复习/短诊断、结束本轮、失败/离线态。

### 4.3 进展（`/records`）

- 三个数字：学过 / 要再练 / 待复习。
- 按日期分组的时间线（今天 / 昨天 / 具体日期）；每行：概念、状态、做题轨迹（几题对几题、用了几次提示、时间）。
- 展开：证据类型、出处页、自评三选（仅本页状态，不声称已保存）。
- 底部低调区：导出 / 删除 / 移除教材关联，走原有确认对话框。

### 4.4 知识地图（`/map`，两级）

- 全册：单元 → 章分组；每章一行，概念胶囊按状态着色；搜索、图例、“回到我正在学的”。
- 章级：按先修关系分层（先学→接着学→再学→连起来），固定节点、同层对齐、无重叠、带箭头连线；选中看详情并可开始学习/复习。
- 列表视图：同一份数据的文字等价物，键盘可走。

## 5. 文案规范

- 人称“你”，动词开头，一条 ≤ 2 行；不解释产品内部模型。
- 禁词（自动扫描）：`内容包`、`activity.`、`source.`、`step-`、`三轴`、`证据候选`、`基准`、`回环`、`rem`、`受控`、`返回位置`、`本地保存`、`当前概念`、`掌握百分比`、`覆盖率`、`评分版本`。
- 允许：`未核实`（全页一次）、`出处`、`课本第 N 页`、`已保存`、`提示`、`跳过`。

## 7. 实施顺序与门禁

1. 外壳与 token（顶栏、三入口、设置）→ typecheck + shell 测试全绿。
2. 今天页 → 截图核对。
3. 学习台 → 三档截图 + 学习流程走查。
4. 地图两级 → 三档截图 + 列表等价。
5. 进展 / 我的课本 / 设置 / 首用 → 文案扫描。
6. 全量 `pnpm typecheck && pnpm test` + 人工清单 + 截图归档 `docs/images/ui/`。

## 8. 设计稿与截图

- 设计稿：`output/uishot/mockups/`（HTML + PNG，临时目录，不入库）。
- 成品截图：`docs/images/ui/`（重构后归档）。
- 实施记录：各步验证结果写入 `docs/PROGRESS.md`。

## 9. 风险

- 测试大量锁死文案/内部 id（约 496 处 `toContain`），需按页面逐批改写；改测试时保留结构与无障碍覆盖。
- 旧契约文档（`02-user-flows`、`07-acceptance`）仍描述旧界面，完成后需同步，避免“文档说必须常驻三轴、实现却收进折叠”。
- 状态矩阵（离线 / 失败 / 待反馈 / 草稿 / 未核实）容易漏，逐页过。
