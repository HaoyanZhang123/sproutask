# 产品契约：DSH 教育垂类重建

> 本文规定目标产品与可观察的交付边界，不宣称这些能力已经实现。决策依据为本次用户明确确认；既有代码与历史文档只提供事实背景。本文与[用户流程](02-user-flows.md)共同约束实现与验收，入口见[交接入口](00-START.md)。

## 1. 不可误读的目标

为使用个人 Windows 电脑的学生提供材料中心的学习工作区：选择与自己教材匹配的版本，从概念地图进入学习或复习，读材料、作答、看结构图、获得解释与纠错，再从本地记录继续上次活动。

DSH 是真实运行内核。教育能力以插件和 Skill 承载，复用其会话、模型调用、工具及受控执行能力，不能做一个外观相似的独立聊天应用再声称“基于 DSH”。技术接入与权限边界由[DSH 集成契约](04-dsh-integration.md)细化。

产品结构允许扩展全学科；本期内容交付范围只有**现有 PDF 实际核实版本的人教版 2024 七年级上册生物学全册概念**。全学科是扩展边界，不是本期内容完成声明；全册是实际目录及概念 inventory 的完整覆盖，不是先展示一张完整样子的地图。

学习目标是获得可回查的理解证据，帮助学生发现、解释并修正概念问题。对话次数、页面访问、活动结束、学生自评分和复习完成都不能直接证明掌握，更不能据此显示“掌握 87%”之类无根据的精确数字。

## 2. 非目标

- 本期不做教师端、班级组织、班级统计、教师查看学生对话、多人协作或跨设备同步。
- 不建设通用 DSH 开发工作台，不把终端、代码编辑、任意工具执行或开发设置放进学生主流程。
- 不把其他教材的自动解析结果包装成已核实内容，不承诺任意教材导入后即有同等质量。
- 不提供考试成绩预测、医学或心理诊断、官方测评认证，不宣称已验证学习效果。
- 不强制学生按目录顺序学习，不以先修关系锁定后续内容，不用补完所有诊断题作为使用门槛。
- 不把引导教学等同于永久拒绝解释或答案；不把云端模型调用称为全离线。
- 本轮交付为交接文档与未来实现任务卡；不实施产品、启动应用或更改既有领域代码契约。

## 3. 固定决策与明确边界

| 主题 | 已确认决策 | 实现时不可偷换的含义 |
|---|---|---|
| 内核与扩展 | DSH 内核，插件 + Skill 教育垂类 | 真实链路必须可追踪；Skill 是教学与内容工作流约束，不拥有绕过后端权限的能力 |
| 用户与设备 | 学生个人 Windows 桌面，本地记录 | 无班级、教师端和同步；本地保存不等于请求内容永不离机 |
| 本期教材 | 实际核实版本的人教 2024 七上生物全册概念 | 文件名、旧样例或常识均不能替代版本与目录核实 |
| 基准复用 | 基准内容一次审校后，匹配版本复用 | 复用的是有版本、出处和审校记录的内容包；每个学生不必重复整本审校 |
| 其他教材 | 自动生成候选，明确未核实 | 与基准分区标识，不能自动继承其核实状态或覆盖当前内容包 |
| 树与图 | 树表示目录；图表示先修或相关 | 目录归属不等于先修；章节靠前不是依赖证据；相关边与先修边可区分 |
| 学习路径 | 建议路径，允许直接进入任意可用概念 | 解释建议理由，允许跳过或转向；缺材料时提示限制而非编造 |
| 教学模式 | 学习、复习两模式 | 练习、讲解、示范、纠错是模式内活动，不再扩成四个平级模式 |
| 教学方式 | 引导优先，允许讲解、示范、确认和纠错 | 学生随时可要提示、解释、示范或跳过，系统不能机械地只反问 |
| 学情表达 | 学习进程、理解证据、复习活动三轴分开 | 判断可回落，有变化原因与证据入口；自评分独立保存与显示 |
| 首次使用 | 自选已学范围 + 短诊断 | 已学范围是学生自述；短诊断有范围与题数说明，允许暂不做或中止 |
| 首版活动 | 文字、选择、结构图标注、关系题、上传图片反馈 | 图片识别不确定要说明；图交互均有键盘和文字等价路径 |
| 首页与导航 | 首页继续上次 / 地图 / 复习；教材库 / 地图 / 工作区 / 记录 | 学生能定位当前教材、概念、模式及返回位置 |
| 布局与材料 | 材料中心；图默认章级展开、局部图 | 不能让全册复杂网络或纯聊天占据默认首屏；不预设视觉组件库 |
| 身份与权限 | 学生凭据与模型服务登录分开 | 学生凭据不授予开发、宿主文件系统、终端或模型配置管理权限；后端裁权 |
| 网络与持久化 | 本地记录，云调用明确告知 | 断网仍可看已有材料和记录；不能把缓存或演示答复伪装成实时反馈 |

这些决策替代历史资料中与本次目标冲突的产品约束。历史实现及质量记录仍可作为证据线索，不能直接作为新方案已完成的证明。具体事实核查归[证据账本](03-evidence.md)；[旧架构](../ARCHITECTURE.md)与[旧规范](../CONVENTIONS.md)保留历史主体，并由入口路由标明适用范围；[工程进度](../PROGRESS.md)记录本轮文档交付，不把计划写成实现。

## 4. 教材、内容审校与全册覆盖规则

### 4.1 先确认“是哪一本”

基准教材必须保留原始 PDF 的本地标识、文件指纹、书名、学科、年级册次、出版社、版次或修订信息及核实依据。核实依据来自实际文件可辨认的封面、版权页、目录和正文，而非单凭文件名。信息无法读清时保持“待核实”，不补填 ISBN、印次、页数或章名。

匹配复用至少同时考虑教材版本标识与内容包版本；文件指纹不同不直接判定教材不同，文件名相同也不直接判定内容相同。匹配不确定时展示差异与依据，让使用者确认或进入候选流程，不能静默套用。正文变更、目录变更或出处变更须使受影响审校结论失效并保留旧记录；仅文件封装变化可在证据支持下维持教材匹配。

### 4.2 inventory 决定“全册”

全册内容制作前须从实际 PDF 建立真实目录与概念 inventory，以 coverage-manifest 冻结来源版本、目录、概念标识、范围和纳入/排除依据，并在[证据账本](03-evidence.md)登记基线。任何改变覆盖分母的修订都应保留前后差异与理由，不能静默覆盖。本契约不预写尚未核实的章名、章节数或概念总数。

inventory 至少区分：目录条目、纳入概念、涉及但不独立成概念的内容、非概念性材料，以及暂无法判定的条目。每个条目有稳定标识、实际目录位置、页码或位置依据、纳入或排除理由、审校状态。跨节概念可复用同一概念实体，但应保留各处教材锚点；同名不同义不能强行合并。

全册完成须同时满足：

1. 真实目录逐项对账，没有未解释的目录缺口；正文、图注、实验及活动中出现的本期概念均纳入盘点，不只提取章节标题。
2. 每个纳入概念都有定义或边界、出处、目录归属、可执行的学习入口、基础理解及变式/迁移活动、反馈依据和理解证据采集方式。不同概念无需强行具有同样的题型，但至少具备两类上述活动以支撑有限理解判断。
3. 先修边与相关边有类型和理由；没有充分理由可不连边。缺边比伪造先修更可接受；不得从目录顺序批量生成先修边。
4. 待核实、遗漏、缺活动、缺出处和有阻断歧义的概念数为零；排除项有理由可审阅，不能靠从分母删除难点宣称全覆盖。
5. 提供覆盖对账表：按章列出目录条目数、纳入概念数、已具备学习入口数、未解决问题数，以及基线版本。可显示“已覆盖 n / 基线 N 个概念”，但必须注明这是内容覆盖，不是学生掌握率。
6. 基准包经过约定的首次审校，留下审校方式、检查范围、问题及修订记录；抽样体验不能替代其余概念的静态覆盖检查。

### 4.3 首次审校的名称必须真实

本轮不执行内容审校。后续首次 AI 静态检查可检查目录对账、概念定义、出处与关系一致性、活动及反馈适配性；它只能标为“已完成首次 AI 静态检查（非专家审核）”，并记录检查范围与遗留风险。不得写成“专家审核”“教师认证”“已通过学生学习实验”或“已证明提升理解”。真实人工复核和学习实验如后续发生，另记参与者角色、方法与实际范围。

“教材版本已核实”“结构提取完成”“首次 AI 静态检查完成”“内容可作为基准复用”是不同结论，不能共用一个勾。可复用基准必须达到覆盖与审校门槛，且无已知阻断问题；检查者、方式与局限始终可查。个别内容仍有争议时保留待审核标记，不把全包泛称为可靠专家内容。

### 4.4 已知旧样例的证据边界

现有[单元样例](../../content/units/u-cell-basic-unit/unit.yaml)只描述一个小节，且显式保留未逐字核对状态；[概念样例](../../content/units/u-cell-basic-unit/knowledge-points.yaml)只有该小节的五条概念记录。它们可帮助理解历史结构，不能证明原始 PDF 版本、全册覆盖、概念关系正确或内容已审校。本次按 PDF 扩展名检查工作区未找到原始 PDF，未检查原始页面；实际教材原文件是全册事实核实的明确前置输入。版本与全册 inventory 的正式核实应由[证据账本](03-evidence.md)提供。不能用旧小节替代原文件，也不能因当前缺少输入而缩减全册目标。软件能力可用自有测试材料验证，测试材料不能冒称目标教材或充当全册覆盖证据。

### 4.5 出处与材料可用性

每个概念及教学依据可定位到教材版本、印刷页码和 PDF 页序；二者不一致时同时展示且明确单位，无印刷页码时说明。不能把 PDF 第 37 页简写为“课本第 37 页”。图示说明来源与是否为教学示意，不能把生成结构图冒充教材原图。

教材正文、学生上传图片和可分发的自编结构分开管理。已有材料未附带或读取失败时，保留准确的出处提示与可用结构，不编造教材原句、不静默换成演示材料。版权及打包边界由[系统设计](06-system-design.md)与[验收方案](07-acceptance.md)承接。

## 5. 学习证据与三轴状态契约

以下名称是供实现统一语义的产品标签，可作等义措辞调整，不能合并其含义。记录结构由[数据契约](05-data-contracts.md)细化。

| 维度 | 表达什么 | 可观察状态示例 | 不得据此推断 |
|---|---|---|---|
| 学习进程 | 学生是否开始或结束一次概念学习活动 | 未开始、进行中、本轮已完成 | 活动完成不等于理解已获支持 |
| 理解证据 | 现有作答支持怎样的概念判断 | 尚无足够证据、需巩固、初步理解、表现稳定 | 访问页面、耗时、连点选项或看过示范不能证明理解；表现稳定不保证长期掌握 |
| 复习活动 | 是否复习过、是否待复习、是否有进行中的会话及最近结果 | 可同时显示“上次已复习 / 目前待复习”，另示本次进行情况与结果 | 不使用单个互斥枚举合并历史、到期、会话及结果；本次完成不等于理解状态自动上升 |
| 自评分（独立字段） | 学生自己的感受 | 不确定、基本会、能解释；可未填写 | 不能替代或覆盖系统证据判断 |

公共数据语义与[数据契约](05-data-contracts.md)一致：学习进程为 not_started / in_progress / completed；理解状态为 unassessed / needs_support / developing / supported。复习分别保存 lastCompletedAt（空表示未复习过）、dueAt、activeSessionId 和 latestOutcome；“已复习”与“待复习”可同时成立。界面只展示清楚的中文。

完成当前学习活动的可观察要求后才能记为 completed；提前离开、跳过或终止不能伪造完成。结束会话与完成活动分别记录，学生仍可自由进入其他概念。理解状态的证据要求以[数据契约](05-data-contracts.md)及逐概念评价依据为准；仅因时间经过应标证据时效与待复习，不能无新证据就断言学生遗忘。

理解判断至少可回查：对应概念、题目或任务、学生原始回答、提示或示范使用情况、反馈理由、时间及内容版本。独立解释、结构关系与迁移作答可形成不同类型证据，单次选择正确只支持有限判断；空白、跳过、未完成识别或取消请求不作为答错。

帮助后重答与独立作答区分记录；直接看过的解释不能立即充作独立证据。新证据与旧判断冲突、内容修订影响既有判断、或后续复习暴露误解时，允许回落到“需巩固”或与现有证据相符的较弱状态，并提示“需要再确认”，展示原因并保留历史。不得为了激励学生只升不降，也不得把模型不确定当作学生不会。

首次自选“已学过”只作为范围自述；短诊断按所选范围采集初步证据，未测部分保持证据不足。诊断失败或跳过不影响进入地图学习。推荐复习可参考证据薄弱、冲突与既往活动，但本期不声称存在已验证的最优记忆算法或精确遗忘概率。

## 6. 需求与可观察条件（R01–R18）

所有条目是目标验收条件，不是本次实现状态。详细走查见[用户流程](02-user-flows.md)，对应证据与自动/人工验收映射见[验收方案](07-acceptance.md)。

| ID | 需求 | 可观察条件 |
|---|---|---|
| R01 | DSH 真实内核 | 从学生提交到模型反馈可追踪到实际 DSH 会话、教育插件与受控工具链；会话恢复复用真实运行状态。验收提供真实调用与失败样例，不能只用假回复或截图证明集成。 |
| R02 | 教材接入 | 教材库可区分本期匹配基准、待核实候选与不可用材料；导入有进度、取消、失败原因和恢复入口。匹配版本可复用既有审校包；未知教材不能自动升为基准。 |
| R03 | 版本页码出处 | 从概念、活动反馈和图示可查教材版本与具体位置，印刷页和 PDF 页序明确区分；定位失败有说明与返回路径，不能编造引用。 |
| R04 | 全册内容 | 按实际 PDF 目录与冻结 inventory 对账，全册纳入概念均满足覆盖规则；缺口和审校问题清零有证据，非概念材料及排除项可解释；不以一个案例或空节点地图代替全册。 |
| R05 | 树图关系 | 同一教材可按目录树和概念图浏览；树显示归属，图明确区分先修与相关且可查理由。默认章级局部图，跨章可显式展开；未学先修只提醒建议，仍可进入目标概念。 |
| R06 | 学习活动 | 从任一可用概念进入学习，能完成材料查看、尝试、提示或解释、反馈和收尾；可请求示范、纠错或跳过。模式内活动覆盖本期适配题型；不无限反问。 |
| R07 | 复习 | 从首页或地图进入复习，可看推荐范围和理由、调整范围、开始、跳过及收尾；保留活动状态与作答，复习完成不自动等于掌握。无待复习项时可自选概念。 |
| R08 | 证据理解 | 每个理解判断能打开证据与理由；学生自评独立显示，使用提示有标记；新冲突可使判断回落并留历史。不显示无依据的精确掌握百分比。 |
| R09 | 三轴状态 | 同一概念同时显示学习进程、理解证据、复习活动的不同含义；可以出现“本轮已完成 / 尚无足够证据 / 上次已复习且目前待复习”，刷新及重启后保持一致，不能用一枚完成勾覆盖三者。 |
| R10 | 图示 | 材料与活动可展示适配的结构图标注和关系题；节点、连线、方向及图例可读，可查来源/示意标识。不能操作图形时用等价文字完成，答案与证据语义一致。 |
| R11 | 批改 | 支持文字、选择及图片上传后的反馈，区分识别文本、评价理由与修改建议；识别不确定或材料不足时先说明并允许确认、重传或改文字。未确认的识别不直接写为明确错答或稳定理解证据。 |
| R12 | 首页恢复 | 首页能继续上次、进入地图或复习；继续时恢复教材版本、概念、模式、活动位置与已保存草稿。首次无记录有明确入口；旧内容失效时说明并允许查看旧记录或进入当前可用内容。 |
| R13 | 新教育 UI | 学生主导航为教材库、地图、工作区、记录，首页聚焦三项核心动作；工作区以材料和活动为中心，聊天辅助。开发入口移出，窄窗和文字放大后仍能完成主旅程；不绑定具体视觉库。 |
| R14 | 身份权限 | 学生凭据与模型服务授权分开呈现；学生登录不等于模型登录成功。隐藏入口之外，后端实际拒绝学生权限下的终端、代码、任意文件或开发管理请求；连接错误不诱导学生粘贴他人密钥。 |
| R15 | 本地持久化 | 返回、刷新和关闭重开后，身份范围内的教材选择、活动、原始作答、证据、自评分及复习状态可恢复；未保存有明确提示。写入失败不显示已保存，不依赖云同步取回记录。 |
| R16 | 扩展 Skill/plugin | 教学策略与学科内容通过明确的教育插件和 Skill 边界扩展；更换或增加学科不要求改动 DSH 内核的通用行为。扩展包声明范围、内容版本和能力，不把未经核实学科标为本期完成。 |
| R17 | 失败取消恢复 | 导入、云反馈、图片识别等有可见运行状态和取消入口；取消保留已保存输入且不判错，失败可重试或改用可用材料。重复点击和重试不重复记答、不跨学生/教材回填旧结果；断网说明可用范围。 |
| R18 | 可验证交付 | 提供可复现的 Windows 主旅程、真实 DSH 接入证据、全册覆盖与审校记录、权限反向验收、持久化及失败恢复验证；报告明确区分静态检查、运行实测、人工走查与未验证项，不以旧测试绿或 AI 自评冒充本期交付通过。 |

## 7. 三种完成不得混同

| 完成层次 | 所需证据 | 不能替代什么 |
|---|---|---|
| 软件功能实现 | DSH 实际链路、导入/地图/教学/权限/本地恢复等功能验收，可使用明确标识的自有测试材料 | 不能据此宣布全册内容就绪 |
| 全册内容就绪 | 目标 PDF 版本核实、coverage-manifest 对账、全部纳入概念具备学习入口、真实审校与集成验收记录 | 首节闭环或少量示例只能是中途验证；静态审校不证明学习效果 |
| 教育实证 | 另行设计并实际完成的学习研究，有方法、对象、分析与局限 | 软件验收、AI 静态检查、专家意见或学生自评均不能冒充学习实验 |

本期交付应同时覆盖软件功能和全册内容；教育实证是独立结论，不是本期可以凭文档宣布完成的能力。首节真实闭环服务于发现问题，全册仍是最终内容目标。

## 8. 交接使用方式与尚缺事实

本契约固定范围和体验行为；数据、架构和实现任务分别由本交接包对应文件定义。技术设计、数据字段、验收用例与实施顺序分别由[DSH 集成契约](04-dsh-integration.md)、[数据契约](05-data-contracts.md)、[系统设计](06-system-design.md)、[验收方案](07-acceptance.md)和[执行交接](08-execution.md)承接；实施任务由 lead 编排。

进入对应真实内容验收或基准发布前仍须取得的事实包括：原始 PDF 实际版本与完整目录、冻结后的概念 inventory、基准包首次审校记录、DSH 可复用能力及须收紧的真实权限边界。它们是需要核实的事实，不是可用猜测补齐的“默认需求”。文档中提到未来验收，不意味着本轮已经运行应用、检查教材原页、完成专家审核或组织学生实验。
