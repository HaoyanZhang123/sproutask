# 手动实测指南（学生界面重构后）

- 日期：2026-11-04（界面 A+B 重构）
- 目的：让你亲手点一遍，确认新的学生界面能用、文案是人话，再决定发布
- 预计 15 分钟；**浏览页面不花钱，只有“提交作答 / 问小芽 / 开始短诊断”会调用模型**

---

## 0. 先启动（1 分钟）

在项目根目录（`E:\DSH\workspaces\ai4edu`）执行：

```powershell
pnpm dev
```

看到 `education web root: http://127.0.0.1:.../?token=...` 后，用浏览器打开这个地址（或等它自动开 Edge 窗口）。

---

## 1. 今天（不花钱）

- [ ] 顶栏只有：芽问 · 今天 / 学习 / 进展 · 设置；**没有**“教材 / 当前概念 / 模式 / 本地保存 / 返回位置”那一长条。
- [ ] 主卡标题是你上次在学的概念，按钮是「继续上次 / 从头开始」。
- [ ] 右栏四行：复习、去目录挑一个概念、看看这周的变化、我的课本。
- [ ] 底部三个数字（学过 / 要再练 / 待复习）和「进展」页一致，说明句是“全册 43 个概念，你已经接触过 N 个”。
- [ ] 页面里没有“内容包”“三轴”“证据候选”“覆盖率”等词。

## 2. 学习台（提交一次，花 1 个回合）

- [ ] 标题下只有一行说明；左右两页在一个大卡里（左课本、右题目），不是三个并排面板。
- [ ] 左页有页码、可折叠「容易混淆 / 这一页的出处」；右页选项是整行，底部只有「需要一点提示 / 先跳过 / 提交作答」（图片题另有「改用图片作答」）。
- [ ] 选一个答案 → 提交 → **原地**出现反馈：结论、依据、出处页码、「下一题 / 再看看材料」。
- [ ] 出处页码不重复、不出现“出处在课本里”这类兜底。
- [ ] 反馈里没有“答案键 / 系统证据 / 不替代”等词，同一句话不重复出现。
- [ ] 右下角「问小芽」能打开对话层，按 Esc 关闭、焦点回到按钮。
- [ ] 窗口缩到 1024 宽：左右两页变成单页，课本收成「课本原文 · 第 2 页」一条，点「看全文」能展开。

## 3. 进展（不花钱）

- [ ] 顶部三个数字；下面是按“今天 / 昨天 / 日期”分组的列表。
- [ ] 点一行能展开：这次看到了什么、证据、出处页、自评三选（不确定 / 基本会 / 能解释）。
- [ ] 列表里没有 `activity.` / `source.` / `step-1` 这类内部 id。
- [ ] 底部「导出或删除学习记录」三个按钮都能弹出确认框（**先别真的删**）。

## 4. 知识地图（不花钱）

- [ ] 全册视图按“单元 → 章”分组，每章一行，概念胶囊带状态文字（在学 / 要再练 / 比较稳 / 还没开始）。
- [ ] 顶部“2 个单元 · 7 章 · 22 节 · 43 个概念”和「已学 N / 43」与「今天」页一致。
- [ ] 点一章进去：概念按“先学 → 接着学 → 再学”分列，节点不重叠、连线不穿过节点。
- [ ] 点一个概念：下方出现详情（说明、状态、出处页、先修/后继），按钮「开始学习 / 先复习」。
- [ ] 右上角「列表」能看到同一份关系的文字版；Tab 键能走完。

## 5. 我的课本（不花钱）

- [ ] 首屏一张卡：书名、出版社、一个状态 chip（待核实 / 已核对，**只出现一次**）、一句“全册多少页、标出多少处原文”。
- [ ] 「课本原文从哪来」默认收起，点开才看到来源列表。
- [ ] 「换一本」「导入新的」可用；导入流程仍能选文件、看进度、取消/重试。

## 6. 设置（不花钱）

- [ ] 模型 Key：只显示“已配置（****）/ 还没有配置”，输入框是密码框，保存/更换/清除可用。
- [ ] 字号能切「标准字号 / 大字」，页面整体变大。
- [ ] 「关于」里的技术信息默认收起（点开才看到 DSH 内核 / 文字模型 / 图像模型）。
- [ ] 没有“受控学习工具 6 项 / 仅本机回环 / 20px 基准字号”这类话。

## 7. 首次使用（不花钱，若已有记录可跳过）

- [ ] 三步说明用学生话；没有本机档案 id、平台账号、“合成 fixture”。
- [ ] 选范围能保存；诊断可跳过；跳过不影响后面学习。

## 8. 键盘与读屏（不花钱）

- [ ] 只用 Tab / Shift+Tab / Enter / Esc 能走完“今天 → 学习 → 提交 → 反馈 → 返回”。
- [ ] 焦点框看得见；弹层打开后焦点在弹层里，关闭后回到原按钮。
- [ ] 所有状态同时有文字，不只靠颜色。
