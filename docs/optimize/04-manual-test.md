# 手动实测指南（学生界面第二轮后）

- 日期：2026-11-03
- 目的：让你亲手点一遍本轮所有改动，确认没问题再打包发布
- 预计 15–20 分钟；**浏览页面不花钱，只有“开始学习/提交/聊天/复习”会调用模型**

---

## 0. 先启动（1 分钟）

在项目根目录（`E:\DSH\workspaces\ai4edu`）执行：

```powershell
pnpm --config.verify-deps-before-run=false --dir education dev
```

终端会打印一行：

```
education web root: http://127.0.0.1:<随机端口>/?token=<一串字符>
```

**把整行 URL（含 `?token=`）复制到 Chrome 或 Edge 打开**。不要手工改端口或去掉 token。

注意事项：

- **只能开一个实例**：数据目录有写锁，重复启动会报 `journal is locked by pid ...`，关掉旧窗口重开即可。
- 浏览器窗口建议拉到 1366 宽以上；缩到很窄会切成单列（预期行为）。
- 停止：在运行命令的终端按 `Ctrl+C`。

## 1. 走查清单（按顺序点）

### ① 首页（不花钱）
- [ ] 左侧导航是 **首页 / 教材库 / 地图 / 工作区 / 记录** 五项，没有开发入口。
- [ ] 页头只有一条上下文条：`教材 7年级上册·生物 | 当前概念 | 模式 | 本地保存 | 返回位置`——**不再有“内容包 版本 2.0.0”**。
- [ ] “继续上次”卡片里**没有** `activity.bio7a...` / `step-1` 这类原始 id，也没有内容包版本号。

### ② 教材库（不花钱）
- [ ] 导语是“确认你用的是哪本教材、哪一版，再看材料从哪里来。”
- [ ] 书目卡片：页数 / 内容范围 / 材料状态；**没有“文件指纹”一行**。
- [ ] 下面标题是「课本原文页码」，默认收着一行「▶ 查看 30 条来源（PDF 页 / 课本页）」；点开才显示列表。

### ③ 地图（不花钱）
- [ ] 导语：“按课本目录找概念；线表示内容之间的关系，点一下就能看详情。”
- [ ] 在右侧关系中点一个概念（例如「观察的含义与地位」）。
- [ ] 下方「出处与材料」**应显示 3 条**：课本第 2 页 / 第 3 页 / 第 5 页，每条后缀“材料在本机可用”——**不再是“该概念还没有登记出处”**。
- [ ] 「关系（3）」每条只剩一行摘要，点「▶ 为什么这样连」才展开长理由。

### ④ 工作区（这里开始花钱）
- [ ] 点「开始学习」进入工作区；材料在左、当前活动在中、学习助手在右。
- [ ] **活动题干只出现一次**；四个选项是**整行卡片**（不是挤成一段），单选按钮圆点可见。
- [ ] 主按钮是绿色「提交作答」；「结束本轮」是普通按钮。
- [ ] 右栏学习助手只有 **给我提示 / 解释一下 / 更多帮助** 三个按钮。
- [ ] 点「更多帮助」→ 出现 **看个示范 / 分步示范 / 直接看答案**；再点一次收起。

### ⑤ 提交一次作答（花钱：1 个回合）
- [ ] 选一个选项 → 点「提交作答」，等 5–20 秒。
- [ ] 反馈里应有**出处（课本第 N 页）**，**不应出现 `source.bio7a...` 这类原始 id**。
- [ ] 如果 AI 直接给了答案，应明确写“disclosure / 后续作答记为 assisted”，且**不应**在答案前面出现“先用一句话说说你的理解：”。

### ⑥ 记录页（不花钱）
- [ ] 三轴分开显示：学习进程 / 理解证据 / 复习安排；自评单独一块。
- [ ] 没有“掌握百分比”。

### ⑦ 边界行为（不花钱）
- [ ] 浏览器按 F5 刷新：会回到首页（这是当前设计：路由在内存里，**不是 bug**）。
- [ ] 关掉浏览器再打开同一 URL：学习记录、草稿仍在。

---

## 2. 花多少钱

- 浏览页面、教材库、地图、记录：**0 次模型调用**。
- 每点一次「开始学习/提交/提示/聊天/复习」= 1 个回合，通常 2–4 次模型调用（个别会长到十几次）。
- 建议本次走查**控制在 10 个回合以内**（约 ¥0.1–0.2）。

---

## 3. 已知问题（不用当 bug 报）

1. **刷新会回到首页**，不保留当前页面（路由在内存）。
2. **探询前缀偶尔与内容不符**：个别回复开头是“先用一句话说说你的理解”，后面却是更正/解释——这是模型信号没标对导致的，已记录，下一轮修。
3. **教材库来源列表最多 30 条**（服务端上限），不是漏了。
4. **首次启动慢**（10–20 秒）是正常的：要起本地服务和加载内容包。
5. 页面里出现“版次/印次未核实”是真实的数据状态，不是 bug。

---

## 4. 怎么反馈

- 一句话 + 截图即可，例如：“④ 选项还是挤在一起”“⑤ 反馈里出现了 source id”。
- 如果都 OK，直接说「没问题，发吧」，我就打包 v0.3.1、写发布说明并更新看板。

## 5. 停止

在运行 `dev` 的终端按 `Ctrl+C`；如果终端关了进程还在，可以：

```powershell
Get-NetTCPConnection -LocalPort <端口号> | Select-Object OwningProcess
Stop-Process -Id <上面的PID>
```
