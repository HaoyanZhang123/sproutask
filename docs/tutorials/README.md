# 芽问 SproutAsk · 零基础使用指南

> 这份文件回答一件事：**我怎么把这个软件打开、用起来、并且确认它是正常的。**
> 全程只需照着抄命令，不需要懂编程。

---

## 0. 先说清楚：它是什么，打开后你会看到什么

它是**一个桌面窗口**（不是网页）。打开后：

1. 屏幕上先出现一句话，问你想做什么，下面四个按钮：**预习 / 复习 / 做题 / 拓展**
2. 你点一个（比如"复习"），窗口变成**左右两半**：
   - **左边**：教材原文（当前是「第二单元第一章第四节 细胞的生活」）
   - **右边**：对话框，你可以像聊天一样提问
3. 教材里的**答案默认是收起的**，写着"先自己想一想，再展开对照"——点一下才会展开
4. 你问问题时，小芽**不会直接给答案**，而是反问你、给线索；它提到出处时，左边教材会自己滚过去并高亮

> 复习 / 做题模式下，左边的教材会**自动收起**（把屏幕让给对话）；预习 / 拓展模式下自动展开。

## 1. 开始前的准备（只做一次）

### 1.1 你需要一个 DeepSeek API Key

这个软件自己不会"思考"，它把思考外包给 DeepSeek（唯一要花钱的地方）。

1. 打开 <https://platform.deepseek.com> ，注册/登录
2. 左侧菜单找 **API Keys** → **创建 API Key** → 复制那串以 `sk-` 开头的字符
3. ⚠️ **它只显示一次**，先粘贴到记事本里存好
4. 充值：先充 **10 元**就够玩很久（本项目预估全程花费几十元量级）

> Key 就是钱，**不要发群里、不要截图、不要上传到任何地方**。本项目的 `.gitignore` 已保证它不会被提交。

### 1.2 确认电脑上有 Node 和 pnpm

打开"终端"（按 `Win + R`，输入 `powershell` 回车），粘贴：

```powershell
node -v
pnpm -v
```

- 两条都输出版本号（如 `v24.19.0`、`11.21.0`）→ 可以继续
- 提示"不是内部或外部命令" → 先装 Node（<https://nodejs.org> 选 LTS），装完重开终端；pnpm 用 `npm i -g pnpm` 装

## 2. 打开软件：四步

### 第 1 步：进入项目目录

```powershell
cd D:\dsh\ai4edu
```

（这是你自己的开发目录。另一份"公开版本"在 `E:\my-project\sproutask`，用法完全一样。）

### 第 2 步：安装依赖（第一次要几分钟，之后不用再装）

```powershell
pnpm install
```

**正常的输出**：最后一行类似 `Done in 3.5s using pnpm v11.21.0`，并且下载约 450 个包。

**如果卡在下载 Electron 或报错**：这是国内网络常见问题，照样抄这两行：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
cd node_modules/electron; node install.js; cd ../..
```

**怎么确认装好了**：下面这条命令应该输出 `True`

```powershell
Test-Path node_modules\electron\dist\electron.exe
```

### 第 3 步：把你的 API Key 告诉软件

```powershell
copy .env.example .env
notepad .env
```

在打开的记事本里，把这一行改掉（**等号后面粘贴你自己的 Key**）：

```
DEEPSEEK_API_KEY=sk-在这里粘贴你的key
```

改成例如 `DEEPSEEK_API_KEY=sk-abc123...`，**保存并关闭**。

> `.env` 这个文件**永远不会被上传**（已被 gitignore）。它只躺在你自己电脑上。

### 第 4 步：启动

```powershell
pnpm dev
```

**正常情况下**：等十几秒到一分钟（第一次会慢），桌面会弹出一个窗口，标题是 **"芽问 SproutAsk"**，
里面是那句开场问句和四个按钮。

**想关掉**：直接关窗口；或者回到终端按 `Ctrl + C`。

## 3. 怎么用（照这个顺序点一遍就是完整流程）

1. 点 **复习**（或预习/做题/拓展任意一个）
2. 右上角出现绿色徽章"复习"，下方显示当前章节
3. 左边出现教材；右边出现一句话"现在开始吧，我会提问，不会直接告诉你答案 🌱"
4. 在右边输入框里打一句话，比如 **"细胞膜有什么用？"**，按回车
5. 小芽会反问你（不会直接答）。回复下面可能有灰色小字（工具/护栏/迭代轮次），那是给开发看的信息
6. 如果小芽提到了"第四节"或"细胞的生活"，**左边教材会自动滚到那一处并高亮黄色**
7. 左边教材里，看到绿色虚线的"先自己想一想，再展开对照"——**点它才会显示答案**
8. 左边上方有搜索框：输入关键词（如 `DNA`）会高亮；若提示"命中都在折叠的答案里"，
   说明答案被收起来了，点"展开看看"才展开

> 左边底部还有"看本节知识点""展开全部答案""全部收起"等小按钮，可以自己点着试。

## 4. 怎么判断"程序是正常的"（最推荐这条）

不用你自己判断——**让程序自己检查自己**。在终端里：

```powershell
$env:SPROUTASK_SELFTEST = "1"; pnpm dev
```

它会自动打开应用、自己点击、自己检查 **26 项**（窗口渲染、四个按钮可见、点模式能进对话、
发消息能上屏、样式生效、教材阅读区在、答案默认收起、点开能看答案、搜索能高亮……），然后打印结果。

**正常的输出结尾**：

```
[selftest] 结果：通过
```

当前目录还会多出一张截图 **`selftest-ui.png`**（可以直接打开看界面长什么样）。

**如果看到 `[selftest] 结果：失败 N 项`** → 把上面那几行 `❌` 的内容发我。

> 每天开机后想快速确认"没坏"，跑这一条就够了。它会自己退出，不需要手动关窗口。

## 5. 可选：终端里对话（更轻量）

不想开窗口、只想聊天时：

```powershell
pnpm chat
```

按提示回复数字选模式（例如输入 `2` 表示复习），然后就可以一直输入问题；输入 `exit` 退出。

## 6. 出问题怎么办（对照表）

| 症状 | 原因 | 处理 |
|---|---|---|
| 窗口没出现，终端报 `Cannot read properties of undefined (reading 'whenReady')` | 环境里有个 `ELECTRON_RUN_AS_NODE` 变量捣乱（模拟 CI 时常留下） | 执行 `Remove-Item Env:ELECTRON_RUN_AS_NODE` 后重跑 `pnpm dev` |
| 窗口里一直提示"连不上外脑"/"还没拿到钥匙" | `.env` 没配好，或文件不在项目根目录 | 确认 `.env` 在 `D:\dsh\ai4edu` 下、Key 粘贴正确（别留着 `sk-在这里粘贴你的key`） |
| 回复说"账户余额用完了" | DeepSeek 余额不足 | 去 <https://platform.deepseek.com> 充值 |
| `pnpm install` 报 `ERR_PNPM_IGNORED_BUILDS` | pnpm 拦截了依赖的构建脚本 | 确认 `pnpm-workspace.yaml` 里有 `allowBuilds`（本仓库已配好） |
| 报 `Error: Electron uninstall` | Electron 二进制没下载好 | 见第 2 步的镜像补装命令 |
| 界面空白 / 报 CSP 错误 | 界面产物有问题 | 先跑第 4 节自检；不行把终端内容发我 |

## 9. 附：项目里都有什么（一页看懂）

| 目录 / 文件 | 大白话解释 |
|---|---|
| `src/main/` | 后台大脑：开窗口、连接模型、管 API Key |
| `src/preload/` | 前台与后台之间的"传话通道"（只转发，无逻辑） |
| `src/renderer/` | 你看到的界面（Vue3 写的） |
| `src/core/` | 教学逻辑：怎么提问、怎么防泄漏答案、怎么组装提示词 |
| `src/shared/` | 前后台都要用的小工具（解析教材里的"折叠块"标记） |
| `content/` | 教材内容（**原文不进 git**，只存结构与知识点） |
| `tests/` | 125 个自动测试 |
| `evals/cases/` | 13 条"教学行为"评测用例（考它会不会直接给答案） |
| `docs/PROGRESS.md` | **进度看这里**（做到哪了、上次干了啥、下一步） |
| `docs/PROGRESS.md` 第 7 节 | 其余文档各自管什么（文档地图） |
| `publish/` | 往 GitHub 发布用的工具（不上传） |
| `notes/` | 调研笔记（不进 git） |
