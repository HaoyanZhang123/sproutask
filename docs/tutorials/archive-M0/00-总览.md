## 1. 我们要造什么

**BioBuddy**——一个住在学生电脑里的初中生物学习 **Agent**。

它知道你们班这周教到哪、你哪个知识点还没过关；不给答案，而是出题、做实验、一步步带你闯关，直到你真正学会。

**和聊天机器人的本质区别**：它有目标（本周章节）、有状态（每个知识点的掌握度）、会调工具（查教材/出题/生成实验/记学情）、有策略（不会就拆简单，会了就进阶）。

完整产品定义见 `../决策与路线.md`。

## 2. 架构（本地优先，不是云端套壳）

```
┌─ 学生电脑：BioBuddy.exe（Agent 本体就在这里）──────────────┐
│  Electron + Vue3 界面（闯关地图 / 对话 / 内嵌互动实验）      │
│  Agent 运行时（TypeScript）：                               │
│   ├─ 工具箱：看教材 / 出题 / 生成HTML实验 / 记学情           │
│   ├─ 学情数据：本地 SQLite（知识点掌握度 + 对话日志）         │
│   └─ 教材全文：当前单元的原文（内置，随请求一起发给 AI）      │
└──────────────┬─────────────────────────────────────────────┘
               └─→ DeepSeek API（唯一的云端依赖）
```

**关键点**：Agent 的目标、状态、工具、策略全在本地；DeepSeek 只是它"打电话咨询的外脑"。

**教材怎么给 AI 看**：不做检索、不做向量化——**把当前单元的教材原文整段放进对话上下文**就行。一个单元正文约 1-2 万字，DeepSeek 的 64K 上下文完全放得下，配合它的上下文缓存，这部分几乎不花钱。好处是简单、可靠，而且**整个项目只需要一个 API Key**。

## 3. 技术栈

| 组件 | 选择 | 理由 |
|---|---|---|
| Agent 运行时 | TypeScript + Node.js（在 Electron 内） | 用 DeepSeek 原生 function calling 实现 Agent 循环，不需要重型框架 |
| 界面 + 桌面壳 | Vue3 + Element Plus + Electron | 中文生态好、AI 辅助编程资料多 |
| 大模型 | DeepSeek V4-Flash API | 国产已备案、便宜（全程50-200元）、支持工具调用；**项目唯一的云端依赖** |
| 教材接入 | **整单元原文注入上下文** | 单元正文1-2万字，64K上下文装得下；配合缓存几乎零成本；无检索失败风险 |
| Python 的角色 | 教材文本提取 + 提示词沙盒（FastAPI） | **开发期工具，不进 exe** |
| 数据存储 | SQLite（本地） | 掌握度模型 + 对话日志 |
| 打包分发 | electron-builder（exe 便携版）+ GitHub Actions（dmg） | 便携版免安装；Windows 打不了 dmg，用免费 macOS 构建机 |

## 4. 名词速查表

- **API**：你写的程序通过它"打电话"给 DeepSeek 请它生成回答
- **API Key**：调用 API 的钥匙，**绝对不能泄露**（不截图发群、不提交公开仓库）
- **Token**：计费单位，约 1.5 个汉字 ≈ 1 token
- **RAG**：先检索教材相关段落、再让 AI 基于这些段落回答——"AI 熟读教材"的原理
- **Embedding（向量化）**：把文字变成一串数字，语义相近的文字向量也相近，于是能"搜意思"而不是"搜关键词"
- **System Prompt（系统提示词）**：每次对话都发给 AI 的"角色设定说明书"，苏格拉底教学规则写在这里
- **function calling（工具调用）**：让 AI 能"决定去用某个工具"（比如查教材、出题），Agent 的核心机制
- **虚拟环境（venv）**：给项目单独隔离的 Python 环境，不污染系统
