# 教程 01：环境准备（Windows）

> ⚠️ **已废弃（M0 时期存档，2026-09 归档）**：本文档写于项目早期，末尾几步围绕已删除的
> Python `backend/` 沙盒展开。**其中"装 VS Code / 装 Node.js"这类通用步骤仍然有效**，
> 但请以仓库根 `README.md` 的「快速开始」为准（当前项目是 TypeScript/Electron，不再需要 Python）。
> 保留本文档仅作学习记录。

> 目标：让你的电脑具备开发条件，并成功调用一次 DeepSeek API。
> 预计耗时：1-2 小时（大部分是下载安装等待时间）。

## 第 1 步：安装 VS Code（代码编辑器）

1. 打开 https://code.visualstudio.com/ ，点击 **Download for Windows**
2. 下载完成后双击安装，一路"下一步"即可（建议勾选"添加到 PATH"和"通过 Code 打开"右键菜单，默认已勾）
3. 打开 VS Code，左侧边栏点"扩展"图标（四个方块），搜索并安装：
   - **Python**（微软官方，Python 代码支持）
   - **Chinese (Simplified) Language Pack**（中文界面，可选）

✅ 验证：能打开 VS Code 即可。

## 第 2 步：安装 Python

1. 打开 https://www.python.org/downloads/ ，点黄色大按钮 **Download Python 3.12.x**
2. ⚠️ **安装时第一件事：勾选最下方的 "Add python.exe to PATH"**（这步漏了以后全是坑），然后点 "Install Now"
3. 安装完成

✅ 验证：按 `Win + R`，输入 `powershell` 回车，在打开的蓝色窗口里输入：
```powershell
python --version
```
显示 `Python 3.12.x` 即成功。如果提示"不是内部或外部命令"，说明 PATH 没勾上——重新运行安装包选 Modify 修复，或直接问我。

## 第 3 步：安装 Node.js（重要：Agent 本体将来跑在这上面）

1. 打开 https://nodejs.org/ ，下载 **LTS** 版本（长期支持版）
2. 双击安装，一路"Next"

✅ 验证：PowerShell 里输入 `node -v`，显示 `v22.x.x` 之类即可。

> 为什么现在就装：最终产品 BioBuddy 的 Agent 运行时是 TypeScript 写的（跑在 Electron 里）。前期教程用 Python 调试提示词和预处理教材，后面会切到 Node。

## 第 4 步：注册 DeepSeek API 并获取钥匙

1. 打开 https://platform.deepseek.com/ ，手机号注册登录
2. 左侧菜单 → **充值**：先充 **10 元** 体验（足够你开发调试很久；整个项目预计 50-200 元）
3. 左侧菜单 → **API keys** → **创建 API key** → 起个名字如 `biobuddy`
4. ⚠️ **key 只显示一次**，立刻复制下来，粘贴保存到一个私密记事本里
   - 它长这样：`sk-xxxxxxxxxxxxxxxxxxxxxxxx`
   - 这是付费钥匙，**不要发给任何人、不要截图发群**

## 第 5 步：创建项目文件夹和虚拟环境

1. 在你喜欢的位置（如 `D盘`）创建项目文件夹。建议路径：`D:\dsh\ai4edu\backend`
2. 打开 VS Code → 文件 → 打开文件夹 → 选择 `D:\dsh\ai4edu`（打开整个项目根目录）
3. 在 VS Code 里按 `` Ctrl + ` ``（反引号，Tab 键上面）打开终端
4. 在终端依次执行（每行回车一次）：

```powershell
# 进入 backend 目录
cd D:\dsh\ai4edu\backend

# 创建虚拟环境（在项目里隔离开一个干净的 Python 环境）
python -m venv .venv
```

5. 激活虚拟环境：
```powershell
.\.venv\Scripts\Activate.ps1
```

⚠️ **如果这一步报错红字"禁止运行脚本"**：执行下面这行（只需执行一次，作用是允许当前用户运行本地脚本），然后再重新执行激活命令：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

✅ 验证：激活成功后，终端每行最左边会出现 `(.venv)` 字样。以后每次打开项目终端，都要先激活虚拟环境（看到 `(.venv)` 再干活）。

## 第 6 步：安装第一批 Python 库

在已激活虚拟环境的终端里执行：

```powershell
pip install fastapi uvicorn openai python-dotenv
```

（国内下载慢的话，用清华镜像：`pip install fastapi uvicorn openai python-dotenv -i https://pypi.tuna.tsinghua.edu.cn/simple`）

- `fastapi`：我们的后端框架
- `uvicorn`：运行后端的"发动机"
- `openai`：调用大模型的 SDK（DeepSeek 兼容 OpenAI 接口格式，所以用它）
- `python-dotenv`：安全读取我们存的 API Key

## 第 7 步：保存 API Key（安全做法）

在 `backend` 文件夹里新建一个文件，文件名**就叫** `.env`（注意开头有个点，没有后缀名），内容写：

```
DEEPSEEK_API_KEY=sk-你的key粘贴到这里
```

> `.env` 文件用来存放密钥，代码里读取它而不是把 key 直接写在代码里——这样代码发给别人看也不会泄露钥匙。这个文件永远不要外传。

## 第 8 步：跑通人生第一次大模型调用 🎉

在 `backend` 文件夹新建 `test_api.py`，内容如下（我已经帮你写好了，直接看项目里的文件）：

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

# 从 .env 文件读取 API Key
load_dotenv()

# 创建客户端：注意 base_url 指向 DeepSeek
client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

# 发起一次对话
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是一名初中生物老师，说话亲切简洁。"},
        {"role": "user", "content": "用一句话向初一学生解释什么是细胞。"}
    ]
)

print(response.choices[0].message.content)
```

终端里运行：
```powershell
python test_api.py
```

✅ 验证：几秒钟后看到 AI 的回答（类似"细胞就像构成生命大厦的一块块小砖头……"），恭喜你，**你的电脑已经能和 AI 对话了**！

如果报错：
- `401 Authentication Error` → API Key 复制错了，检查 `.env`
- `Insufficient Balance` → 没充值
- 超时/网络错误 → 检查网络，或公司/校园网有限制
