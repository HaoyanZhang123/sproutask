# 研习设计：理论框架、研究方法与报告结构

> 本项目既是**产品开发**，也是一份**教育研习课题**。本文件是研习的"设计图纸"：
> 交付要求 → 题目 → 研究问题 → 理论框架 → 方法 → 伦理 → 报告结构 → 文献方向。
>
> 交付格式以《北京师范大学师范生教育研习报告》空白表为准：**封面 + 摘要 + 报告正文 +
> 指导教师意见 + 部院系意见**（表格未附字数与评分细则——需向学院/指导教师确认）。

## 3. 研究问题

| # | 问题 | 类型 |
|---|---|---|
| RQ1 | 如何设计一个**以教材与课标为准、以引导而非告知为原则**的初中生物 AI 学习伙伴？（设计原则、提示词策略、防泄漏护栏、内容结构） | 设计 |
| RQ2 | 学生在**预习 / 复习 / 做题 / 拓展**四类任务中如何与 AI 交互？对话中呈现出哪些学习行为特征（提问类型、求助时机、提示依赖）？ | 描述 |
| RQ3 | 使用该工具后，学生对目标概念的**理解**与**学习体验**有何变化？ | 效果 |
| RQ4 | 开发与试用中暴露了哪些**技术与教学问题**（答案泄漏、过度依赖、教材外发挥、超纲）？如何改进？ | 反思 |

> RQ1/RQ4 由开发过程本身回答（设计型研究）；RQ2/RQ3 由问卷、对话记录与课堂观察回答。

## 4. 理论框架

| 理论 | 与本项目的连接 | 落到产品的哪里 |
|---|---|---|
| **建构主义**（知识由学习者主动建构） | 反对"直接告知"，坚持引导 | L1 教学纪律："永不直接给完整答案" |
| **最近发展区 + 支架式教学**（Vygotsky; Wood, Bruner & Ross, 1976） | 提示要"够得着但够不全"，并逐步撤除 | 分级提示（先诊断问→提示→拆简单）；连续两次答错才加提示 |
| **苏格拉底式诘问** | 对话结构的基本形态 | 反问式回复；每次只推进一小步 |
| **概念转变理论**（Posner et al., 1982：对原有概念不满、新概念可理解/合理/有效） | 常见误区是设计的起点，认知冲突是提问的抓手 | `KnowledgePoint.misconceptions` 字段；针对误区的诊断性提问 |
| **元认知与自我调节学习**（Zimmerman, 2002） | "先自己答、再对照答案"促进自我监控 | **教材阅读区的折叠答案**（先答后展） |
| **认知负荷理论**（Sweller, 1988） | 界面与回复要降低外在负荷 | 回复 ≤150 字；答案默认折叠；对话与教材分区 |
| **自我决定理论**（Deci & Ryan, 2000：自主 / 胜任 / 关系） | 学生自选模式给"自主"；过关给"胜任" | 开场**学生四选一**（预习/复习/做题/拓展）；掌握度推进 |
| **反馈理论**（Hattie & Timperley, 2007：去哪·现在在哪·下一步） | 反馈要指向"下一步"而非只判对错 | 掌握度三态 + 每次反馈指向下一步 |
| **人机协同与 AI 教育伦理**（国内：黄荣怀、余胜泉、卢宇等团队） | 定位为"辅助"而非替代教师；防过度依赖 | 超纲转交真人老师；使用时长约定；不做教师端以保护隐私 |

## 5. 研究方法

**总体：设计型研究（Design-Based Research, DBR）**——"设计 → 实施 → 分析 → 再设计"多轮迭代，
天然匹配"边做产品边研究"的实习情境（Design-Based Research Collective, 2003）。

**流程（对应实习期）**：

| 阶段 | 活动 | 产出（研习数据） |
|---|---|---|
| 分析 | 教材/课标分析、学情观察、确定知识点与常见误区 | 知识点表、误区清单 |
| 设计 | 提示词分层设计、护栏设计、界面与模式设计 | 提示词 v1/v2 版本与迭代记录 |
| 实施 | 小范围试用（受控环境，问卷为接触渠道） | 对话记录（本地、匿名）、课堂观察笔记 |
| 评价 | 前后测问卷、对话内容编码、开发者反思 | 数据表与分析结论 |
| 再设计 | 依据结果修订提示词与内容 | 改进说明（可写进讨论） |

**数据来源与工具**：

1. **前测问卷**：已有概念水平（目标知识点的概念题）、AI 使用经验、学习习惯
2. **对话记录**：本地存储；经同意后匿名化用于类型编码
3. **后测问卷**：概念题（同前测平行）+ 使用体验量表（易用性、帮助度、是否觉得"被引导而非被告知"）
4. **课堂观察记录**：教师在场观察（参与度、卡点、情绪）
5. **开发者反思日志**：提示词每次改动的原因与效果（`evals/reports/` 留存）

**分析方式**：
- RQ3：前后测**配对比较**（样本小时以描述统计 + 个案分析为主，不做过度推断）
- RQ2：对话**内容编码**（提问类型 / 是否先自答 / 提示次数 / 触发护栏次数 / 超纲次数），
  编码框架在附录给出，做信度说明（如两名编码者一致性）
- 关键指标：**答案泄漏率**（护栏命中率）、**引导成功率**、**平均提示次数**、**概念题得分变化**

**样本与局限（须在讨论中主动声明）**：
1 个班（约 30–45 人）、自愿参与、无随机分配、实习期仅数周、存在霍桑效应与新奇效应；
结论定位于"本班情境下的实践探索"，不做普适性推广。

### 问卷设计规范（对照先例，可直接执行）

先例的问卷做法（22 个量表题 + 1 个成绩段分类题，四维度，李克特五点，含反向题，
做了信效度检验）已验证可被接受，我们照此规格做**前后测两份问卷**。

**(1) 卷首语（必须含这几句）**
> 说明目的（仅供研究）→ **严格保密** → **不评价你生物学习的好坏** → **不会对你的学习生活造成
> 任何影响** → 说明作答方式（五选一）→ **答案无对错之分** → 致谢。

**(2) 题量与维度**（建议：总量控制在 20–25 题，10 分钟内可完成）

| 维度 | 题量 | 示例（后测） |
|---|---|---|
| 概念理解（前后测平行） | 6–8 | 光合作用的原料/产物/条件（学科知识题，非量表） |
| 学习体验与引导感知 | 5–6 | "它会引导我自己想，而不是直接告诉我答案" |
| 使用意愿与自我效能 | 3–4 | "我还愿意用它复习其他章节" |
| 认知负荷 | 3–4 | "和它对话时我要记的东西太多、有点累"（**反向题**） |
| 依赖与诚信 | 2–3 | "我有时想让它直接给我作业答案"（**反向题**） |
| 分类题 | 1–2 | 成绩段、此前是否用过 AI（供分组分析） |

**(3) 计分**：李克特五点（完全不符合 / 不符合 / 不确定 / 符合 / 完全符合），正向题计 1–5 分；
**反向题反向计分**，分析前统一正向化（先例同样处理）。

**(4) 附录必须给"维度—题号对应表"**（先例的附录 2 就是这张表，便于他人在报告外复现与审阅）。

**(5) 信效度**：样本虽小仍应报告——Cronbach's α（总体与各维度）、KMO 与 Bartlett 球形检验；
α 与 KMO 的判读标准**必须标文献**（见「先例约束」第 2 条）。样本量过小时，如实说明其局限，
不硬套因子分析。

**(6) 统计方法选择顺序**（照先例的谨慎做法）：
先做**正态性检验**（n<50 用 S-W）→ 符合正态且方差齐则用 t 检验 / 单因素方差分析；
不符合则改用**非参数检验**（曼-惠特尼 U）。
本项目样本更小，默认以**描述统计 + 配对比较 + 个案分析**为主，显著性检验仅作参考。

**(7) 身份信息**：先例收集了姓名；**我们只收编号**（与产品合规一致：S01…），
真实姓名与编号的映射表单独保存、不录入数据集、不写入报告。

## 6. 伦理与合规

| 要求 | 做法 |
|---|---|
| 家长知情同意 | 学生多不满 14 周岁 → **监护人单独同意**（书面），载明目的、范围、存储、期限、退出方式 |
| 学生本人同意 | 学生 assent，可随时退出且不影响任何评价 |
| 学校审批 | 方案报实习学校教务处/信息中心；指导教师认可 |
| 高校伦理 | 院系学术委员会/伦理委员会备案（按学院要求） |
| 数据最小化 | 学生**只用编号**（S01…）；不收集姓名、电话等；不做教师端查看对话 |
| 存储与删除 | 数据仅存本地；研习结束限期删除或匿名化 |
| 使用边界 | **以问卷为接触渠道**、受控环境限时体验；不公开传播；不做商业化 |
