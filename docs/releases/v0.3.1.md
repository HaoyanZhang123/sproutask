## 中文

这一版把学生界面从“工程版”收拾成“学生能直接看懂”，并修掉了几处会让 AI 答非所问的教学对话缺陷。教材原文与学习记录仍然只留在本机，云端只承担推理。

**优化（界面）**

- 页面文案改成学生语言：去掉「内容包 版本 2.0.0」这类工程信息、页脚权限说明和规格式导语；侧栏补上「首页」。
- 活动题干只出现一次；选项从“挤成一段”改成整行卡片；「提交作答」恢复为主按钮。
- 出处按页去重，并用「课本第 2 页」这样的说法；首页与账户页不再出现 `activity.*`、`learner.*` 等内部标识。
- 教材库去掉文件指纹，30 条来源收进「查看来源」折叠块。
- 学习助手默认只显示两个常用帮助，其余收进「更多帮助」。
- 地图的出处与关系理由收进可展开的详情，「出处与材料」不再永远显示为空。

**修复（教学对话）**

- 模型现在能看到整册收录目录（2 单元 / 7 章 / 22 节 / 43 概念），不再对内容包里已有的概念说“可能不在内容包”或让学生猜是哪一节。
- 本轮教学上下文（当前概念、材料、活动、前置概念、证据摘要）现在会随消息送达模型；此前只发了学生原话。
- AI 给出完整答案时，不会再在前面挂一句「先用一句话说说你的理解」。
- 学生界面不再出现内部 `source.*` / `activity.*` 标识（包括产品自己生成的参考行）。
- 新增页码守卫：只保留本轮工具确实返回过的页码，未获支持的页码改写为「课本相应页（页码以出处为准）」。
- 单回合工具调用上限从 10 提到 14，避免合法回合因为多调了几次工具而整轮没有回答。

**重要说明**

- 安装包**未签名**，Windows 会提示“未知发布者”；包内附 `SHA256SUMS.txt` 供校验。
- 仍是工程冻结版：图义视觉核对只完成抽样、未做干净机验证、未做学习效果实验；部分回复的探询前缀可能与内容语义不完全匹配（已记录，下一轮处理）。
- 本版发布在分支 `education-v0.3.1`。

## English

This release turns the student-facing UI from an engineering build into something a student can read, and fixes several teaching-dialogue defects that made the assistant answer the wrong question. Textbook text and learning records still stay on the local machine; the cloud is used for reasoning only.

**Improved (UI)**

- Page copy is written for students: engineering metadata such as "content pack version 2.0.0", permission notes in the footer and specification-style introductions are gone; the sidebar now has a Home entry.
- The activity stem is shown once; options are full-width cards instead of one run-on paragraph; "Submit answer" is the primary button again.
- Sources are de-duplicated per page and phrased as "textbook page 2"; home and account pages no longer expose internal ids such as `activity.*` or `learner.*`.
- The library drops the file fingerprint and folds its 30 source rows into a "view sources" block.
- The study assistant shows two common help actions by default; the rest live behind "more help".
- Map sources and relation rationales are folded into expandable details; "sources and material" is no longer permanently empty.

**Fixed (teaching dialogue)**

- The model can now see the whole volume's table of contents (2 units / 7 chapters / 22 sections / 43 concepts), so it no longer claims that a concept already in the pack "may not be included" or asks the student which section they mean.
- The turn context (current concept, material, activity, prerequisites, evidence summary) now reaches the model; previously only the student's own words were sent.
- A full answer is no longer prefixed with "first tell me what you understand in one sentence".
- Internal `source.*` / `activity.*` ids no longer appear in the student UI, including the reference line the product itself generated.
- New page guard: only page numbers actually returned by tools in that turn are kept; unsupported numbers are rewritten as "the corresponding textbook page (see sources)".
- The per-turn tool-call cap moved from 10 to 14 so a legitimate turn is not killed with no answer for calling a few extra tools.

**Important notes**

- The installer is **not code-signed**; Windows shows an "unknown publisher" prompt. `SHA256SUMS.txt` is included for verification.
- This is still a frozen engineering build: figure-caption review is sampled only, no clean-machine validation, no learning-effect experiment, and a few replies still open with a probing line that does not match the content (recorded for the next round).
- This release ships on branch `education-v0.3.1`.
