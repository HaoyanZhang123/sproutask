# SproutAsk v0.4.0

> 发布日期：2026-11-04。学生界面重构（A+B）与工作区收拢版本。安装包未签名。

## 中文

本次更新把学生界面从"工程版"重做成"学生能直接用"的界面，并把仓库收拢成只有 DSH 教育线一条产品线。

**变更概览**：新增 3 项 · 优化 7 项 · 修复 5 项

**新增**

- 知识地图两级视图：全册章节总览（单元 → 章 → 概念状态）+ 章级先修关系图，并提供文字等价列表与键盘操作。
- 学习台：左页课本、右页练习，提交后结论、依据与出处原地展开；窄于 1100px 时变单页并把课本收进抽屉。
- 界面质量守卫：学生文案禁词自动扫描（`copy-guard`）与 1440×900 / 1280×800 / 1024×768 三档截图走查。

**优化**

- 顶栏改为「今天 / 学习 / 进展 + 设置」，去掉侧栏、调试状态条与服务状态卡。
- 今天页：接着上次、今天可做、与进展页同口径的三个学习数字。
- 进展页：三个数字 + 按日期时间线 + 可展开的证据、出处与自评；导出删除收在页面底部。
- 我的课本：一页一张课本卡，`待核实` 标识全页只出现一次，来源收进折叠块。
- 设置与首次使用改成学生话；错误提示不再显示错误码，统一为"发生了什么 + 怎么办"。
- 全站文案减法：删除或压缩 30 处小字解释（版式说明、系统自证、重复隐私、冗长确认框、重复计数），移除全局页脚。
- 仓库收拢：删除旧 Electron/Vue 线，根目录入口、CI、文档与看板统一到 `education/`。

**修复**

- 首页与知识地图"已学"计数口径不一致（同一指标两页数字不同）。
- 进展页泄露 `activity.*`、`source.*`、`step-*` 等内部 id。
- 知识地图单元名重复显示、同层"相关"虚线穿过节点。
- 学习反馈重复句、"答案键"等内部词上屏、出处页码重复。
- 答题区一次并排 6 个按钮，以及答对后仍显示「改文字再试」。

**重要说明**

- 安装包**未做代码签名**，Windows 会提示"未知发布者"；发布页附 `SHA256SUMS` 供校验。
- v0.4.0 尚未做干净机验证，也没有学习效果实验；不声称提升理解或成绩。
- 已知缺口：live 数据源暂不支持 `activityId`（「下一题」可能诚实降级为再答一次）；自评尚未通过 shell API 落库；进展页章节名与真实印刷页码映射不完整。详见 README 的"当前状态与已知限制"。

## English

This release turns the student UI from an engineering build into something a student can use, and consolidates the repository to the DSH education line only.

**Summary**: Added 3 · Improved 7 · Fixed 5

**Added**

- Two-level knowledge map: a whole-volume chapter overview (unit → chapter → concept state) plus a layered prerequisite graph for one chapter, with a text-equivalent list and keyboard support.
- A single study desk: textbook page on the left, question on the right; after submitting, the verdict, reasoning and sources expand in place. Below 1100 px it becomes one page with a textbook drawer.
- UI quality guards: an automated banned-copy scanner (`copy-guard`) and screenshot review at 1440×900 / 1280×800 / 1024×768.

**Improved**

- Top bar is now Today / Study / Progress + Settings; the sidebar, debug status strip and service-status cards are gone.
- Today page: continue-last, today's actions, and three learning numbers that match the Progress page.
- Progress page: three numbers, a date-grouped timeline, expandable evidence/sources/self-report, and export/delete at the bottom.
- My textbook: one book card, a single `待核实` badge, and sources folded away.
- Settings and first-run now use student language; error banners no longer show error codes and instead say what happened and what to do.
- Copy reduction across the app: 30 small-print explanations removed or shortened (layout instructions, self-justifying notes, repeated privacy lines, verbose confirmation dialogs, duplicate counts); the global footer is gone.
- Repository consolidation: the old Electron/Vue line is removed; root entry points, CI, docs and the dashboard all target `education/`.

**Fixed**

- "Learned" counts disagreed between Today and the knowledge map.
- The progress page leaked internal ids such as `activity.*`, `source.*` and `step-*`.
- Duplicate unit labels on the map and same-layer relation edges crossing nodes.
- Duplicate feedback sentences, internal terms such as "answer key" shown to students, and repeated source pages.
- Six buttons crowded next to an answer, and "edit answer" still shown after a correct answer.

**Important notes**

- The installer is **not code-signed**, so Windows shows an "unknown publisher" prompt; a `SHA256SUMS` file is included on the release page.
- v0.4.0 has not been validated on a clean machine and no learning-effect study has been run; no claim of improved understanding or grades is made.
- Known gaps: the live data source does not yet honor `activityId` (so "next question" may degrade honestly to re-answering), self-report is not persisted through the shell API, and chapter labels / printed-page mapping are incomplete in the progress view. See "Current status and limits" in the README.
