## 中文

本次更新把芽问从 Electron 桌面应用改为运行在真实 DSH 内核（`@deepseek-ai/dsh` 0.2.1-rc.3）上的教育 Agent：本机后台服务加一个应用窗口，不需要 Electron，也不需要管理员权限。学习数据仍然只留在学生自己的电脑上，云端只用于推理。

**变更概览**：新增 8 项 · 优化 4 项 · 修复 3 项

**新增**

- **DSH 内核运行时**：改为本机服务 + 应用窗口，按用户安装到 `%LOCALAPPDATA%\SproutAsk\current`，不再依赖 Electron。
- **全册教材内容包**：1 册 / 2 单元 / 7 章 / 22 节 / 43 概念 / 88 活动 / 43 评分细则 / 44 条关系，193 个去重出处（281 条出处引用），经人工逐项审校后为 `status=published`。
- **四个学习界面**：教材库 `/library`、概念地图 `/map`、工作区 `/workspace`、记录 `/records`。
- **三轴学习状态与复习落账**：概念状态随学习流程推进，复习通过 `finish-review` 记录，而不是从翻页行为推断。
- **核心误解反馈**：概念未达成时给出「具体误解 + 正确说法 + 教材出处」，而不是只判对错。
- **图片作答质量门**：模糊、倾斜、空白图片在调用模型前被拦截并要求澄清；通过的图片判分幂等。
- **双页码锚点**：反馈同时给出 PDF 页码与印刷页码。
- **两种分发包**：一键安装（免管理员）与便携包；许可证与 NOTICE 随包分发。

**优化**

- 首节完整旅程在安装版、隔离数据根下实测通过，包含重启后草稿一致。
- 安装后冒烟：启动 1.75 s、服务返回 200、`trustMode=published`、43 个概念可读。
- 质量门：`contract-lock` 通过（456 个文件 / 21 条命令）、测试 642 例全绿、自检 46/46、`content:validate` 退出码 0。
- NOTICE 生成器改为以随包 payload 实测为准：558 = 546 随包 + 12 裁剪，连跑两次四文件哈希一致。

**修复**

- `build-notice.mjs` 损坏（BOM 与 GBK 乱码导致 `node --check` 报语法错误）→ 重写为 `build-notice-v2.mjs`，坏文件保留为 `.broken` 存证。
- NOTICE 里「sharp 已裁剪」与实测不符 → 改为随包声明，`EXCLUDED.md` 只列 12 个真裁剪包并注明 sharp 不在其中。
- 陈旧 journal 锁导致启动被卡 → 120 秒 TTL 自愈，半行写入与坏快照有降级路径。

**重要说明**

- **产物未做代码签名**：SmartScreen 会提示「未知发布者」，需手动选择「仍要运行」。维护者未购买签名证书。
- **已知限制（真实存在、尚未解决）**：图义视觉核对只抽样 8/73（一致 7、无法判断 1），其余 65 张未核对，且结论来自会话内视觉模型而非人眼签字；版次/印次/定价/开本未核实（仅确认 ISBN-13 `978-7-107-38263-5` 与人民教育出版社）；没有第二台 Windows 机器做干净机验证；没有真实浏览器/设备截图，界面只有离线断言；手机拍照与澄清后重试路径未在真机验证；**学习效果实验未做，不声称提升理解或成绩**。
- **门状态如实**：G1 = PARTIAL、G2 = FAIL/PARTIAL、G3 = PARTIAL，最上层 `finalAccepted` 门**不可达**。
- **升级建议**：0.3.0 与 Electron 0.2.x 线不共用数据目录，旧学习数据不会自动迁移。存储层提供显式迁移能力（不自动运行、迁移前先备份、逐行写回执、旧的 `mastered` 只记为「已学完、理解未评估」），但本期验收未覆盖真实旧数据迁移——升级前请保留旧版目录以便回退。

## English

This release moves SproutAsk off the Electron shell and onto the real DSH kernel (`@deepseek-ai/dsh` 0.2.1-rc.3). The application is now a local background service plus an application window: no Electron, no administrator rights. Learning data still stays on the student's own machine, and the cloud is used for inference only.

**Summary**: Added 8 · Improved 4 · Fixed 3

**Added**

- **DSH runtime**: a local service plus an application window, installed per user into `%LOCALAPPDATA%\SproutAsk\current`, with no Electron dependency.
- **Full-volume content pack**: 1 volume / 2 units / 7 chapters / 22 sections / 43 concepts / 88 activities / 43 rubrics / 44 relations, with 193 distinct source anchors (281 reference entries), reviewed item by item by a human curator and set to `status=published`.
- **Four study surfaces**: library `/library`, concept map `/map`, workspace `/workspace`, records `/records`.
- **Three-axis learning state and review accounting**: concept state advances through the study flow, and review is recorded through `finish-review` instead of being inferred from page visits.
- **Misconception feedback**: a missed concept returns the specific misconception, the correct account, and the textbook source, rather than a right/wrong verdict.
- **Photo quality gate**: blurred, rotated and blank images are rejected with a clarification request before any model call; accepted images score idempotently.
- **Dual page anchors**: feedback carries both the PDF page and the printed page.
- **Two distribution forms**: a per-user one-click installer and a portable zip, with licenses and NOTICE shipped alongside.

**Improved**

- The first-section journey passes end to end on the installed build with an isolated data root, including draft consistency after a restart.
- Post-install smoke: 1.75 s to launch, service returns 200, `trustMode=published`, and 43 concepts are readable.
- Quality gates: `contract-lock` passes (456 files / 21 commands), 642 tests green, self-check 46/46, `content:validate` exits 0.
- The NOTICE generator now reports what the shipped payload actually contains: 558 = 546 shipped + 12 excluded, with all four output files hashing identically across two consecutive runs.

**Fixed**

- `build-notice.mjs` was broken (BOM plus GBK mojibake made `node --check` fail with a syntax error) and has been rewritten as `build-notice-v2.mjs`, with the broken file kept as `.broken` for the record.
- NOTICE claimed sharp had been excluded, which the payload contradicted; it now declares sharp as shipped, and `EXCLUDED.md` lists only the 12 genuinely excluded packages.
- A stale journal lock could block startup; it now self-heals after a 120-second TTL, and half-written lines and bad snapshots degrade safely.

**Important Notes**

- **The binaries are not code-signed.** SmartScreen warns about an unknown publisher and you must choose "Run anyway". No signing certificate was purchased.
- **Known limitations, unresolved.** Figure-meaning verification was sampled at 8 of 73 figures (7 consistent, 1 undecidable); the other 65 were not checked, and that judgement came from a vision model in-session, not a human sign-off. Edition, printing, price and trim size are unverified (only ISBN-13 `978-7-107-38263-5` and the publisher, People's Education Press, are confirmed). There is no second Windows machine for clean-machine validation. There are no real browser or device screenshots; the interface has offline assertions only. Phone capture and the retry-after-clarification path were not tested on a real device. **No learning-outcome experiment was run, and this release does not claim improved understanding or grades.**
- **Gate status, stated plainly.** G1 = PARTIAL, G2 = FAIL/PARTIAL, G3 = PARTIAL, and the top-level `finalAccepted` gate is **not reachable**.
- **Upgrading.** v0.3.0 does not share a data directory with the Electron 0.2.x line, and old learning data is not migrated automatically. The storage layer does provide explicit migration (never automatic, backs up the source first, writes one receipt per line, and records a legacy `mastered` flag only as "studied, understanding unassessed"), but acceptance this release did not cover migrating real legacy data — keep the old directory for rollback before upgrading.
