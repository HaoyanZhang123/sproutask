## 中文

本次发布把芽问从 Electron 桌面应用替换为运行在真实 DSH 内核（`@deepseek-ai/dsh` 0.2.1-rc.3）上的教育 Agent：本机后台服务 + 一个应用窗口，不再需要 Electron，也不需要管理员权限。教材原文与学习记录仍然只留在学生本机，云端只承担推理。

**变更概览**：新增 8 项 · 优化 4 项 · 修复 3 项

**新增**
- 真实 DSH 会话与教育工具链：回答携带教材出处（PDF 页与印刷页分列），可追溯到 source id。
- 全册内容包（人教 2024 七上生物）：2 单元 / 7 章 / 22 节 / 43 概念 / 88 活动 / 43 rubric / 44 关系 / 281 条出处，经人类审校后发布。
- 三条独立状态轴：学习进程、理解证据、复习活动分开记录与显示；自评独立保存。
- 复习落账：先回忆再反馈，结束后记录"复习完成·仍需巩固"，不会把复习完成写成理解达成。
- 图片作答：上传前后先过独立质量门（模糊/倾斜/空白直接澄清，不调用模型），通过后判分并幂等落库。
- 模型 Key 由学生在 `/account` 录入，本机 DPAPI 加密存储，重启后由宿主解密注入，客户端不可见。
- 一键安装包与便携包（免管理员、用户级数据目录），附第三方许可清单与 LGPL 义务说明。
- 章节级概念地图：目录树与先修/相关图分开，先修边必须带依据。

**优化**
- 单回合预算（45 秒 / 10 次工具调用），超限返回结构化错误并保留已取得的来源，不再静默回退本地规则。
- 回合文本选取改为"本回合最后一条有正文的 assistant"，避免推理末步吞掉回答。
- 学习日志锁支持陈旧自愈（120 秒 TTL + 心跳），修掉强杀后打不开的问题。
- 会话 id 分配扫描 DSH 会话存储，重启后不再撞号。

**修复**
- 重启后第一次"开始学习"报会话恢复错误的问题。
- 模型已给完整讲解但仍被标记为"未披露"的证据归类错误。
- 复核发现的若干契约与文档不一致（发布前统一到 MIT 与同一口径）。

**重要说明**
- 安装包**未签名**，Windows 会提示"未知发布者"。
- 图义视觉核对只抽样 8/73；版次/印次/定价未核实；未做干净机验证与学习效果实验。
- 门状态：G1 PARTIAL · G2 FAIL/PARTIAL · G3 PARTIAL，最终验收未达成。请按"工程冻结版"使用。

## English

This release replaces the Electron desktop app with an education agent running on the real DSH runtime (`@deepseek-ai/dsh` 0.2.1-rc.3): a local service plus an application window — no Electron, no administrator rights. Textbook text and learning records stay on the student's machine; the cloud is used for reasoning only.

**Summary**: Added 8 · Improved 4 · Fixed 3

**Added**
- Real DSH sessions with an education toolchain: answers carry textbook citations (PDF page and printed page as separate fields) and resolve to a source id.
- Full-volume content pack (PEP 2024 Biology, Grade 7 Vol. 1): 2 units / 7 chapters / 22 sections / 43 concepts / 88 activities / 43 rubrics / 44 relations / 281 source references, published after human review.
- Three independent axes: learning progress, understanding evidence and review activity are stored and displayed separately; self-report is kept apart.
- Review accounting: recall first, then feedback; completion is recorded as "reviewed, still needs support" and never as achieved understanding.
- Image answers: an independent quality gate runs before any model call (blurry, tilted or blank photos are sent back for clarification), and graded images are persisted idempotently.
- Model key entered by the student in `/account`, DPAPI-encrypted locally, decrypted by the host after restart, never visible to the client.
- One-click installer and portable package (no admin rights, per-user data directory) with third-party notices and LGPL obligations.
- Chapter-level concept map: directory tree and prerequisite/related graph are separate; prerequisite edges must carry a basis.

**Improved**
- Per-turn budget (45 s / 10 tool calls): on overrun the runtime returns a structured error and keeps the sources already retrieved instead of silently falling back to local rules.
- Turn text selection now uses the last assistant message that actually has text, so a reasoning-only final step no longer discards the answer.
- Journal lock self-heals (120 s TTL plus heartbeat), fixing the "cannot start after force-kill" failure.
- Session id allocation scans the DSH session store, so ids no longer collide after restart.

**Fixed**
- The first "start learning" after a restart no longer fails with a session-resume error.
- Answers the model actually disclosed are now marked as disclosed, correcting the assisted/independent evidence classification.
- Several contract and documentation inconsistencies found in review were aligned (MIT and one consistent wording before release).

**Important notes**
- The installer is **not code-signed**; Windows shows an "unknown publisher" prompt.
- Figure captions were visually checked on 8 of 73 samples only; edition/printing fields are unverified; no clean-machine run and no learning-effect study.
- Gate status: G1 PARTIAL · G2 FAIL/PARTIAL · G3 PARTIAL; final acceptance is not reached. Treat this as a frozen engineering build.
