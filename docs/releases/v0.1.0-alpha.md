芽问 SproutAsk：面向初中生物的"教材锚定对话学习"工具——用苏格拉底式提问带学生读课本、自己想，而不是直接给答案。

## 这是什么

一个装在电脑上的初中生物学习伙伴。它和聊天机器人最大的区别：

- **不直接给答案**：先反问、给线索，带你自己把知识想明白
- **每句话都有出处**：解释只来自课本与课程标准
- **答案默认收起**：教材里的"想一想 / 答案"折起来，先自己答、再展开对照

当前案例单元：人教版《生物学》七年级上册 第二单元第一章第四节「细胞的生活」。

## 怎么用（三步）

1. 下载下面的 **SproutAsk-0.1.0-win-x64.exe**（72 MB，**免安装**，双击就能开）
2. 第一次打开会请你填一个 DeepSeek API Key（在 platform.deepseek.com 的「API Keys」里创建，先充 10 元就够用很久）——界面上有「**先试连一下**」，可以先确认这台电脑能不能连上
3. 填好保存，就能开始用了。以后再打开不会再问；想改 Key 点右上角「设置」

> ⚠️ 首次运行 Windows 可能弹「已保护你的电脑」（本版**尚未做代码签名**）：
> 请点「**更多信息**」→「**仍要运行**」。

## 这一版（alpha）有什么

- **意图询问**：开场先问"今天想做什么"，四选一（预习 / 复习 / 做题 / 拓展）
- **对话 + 教材阅读视图**：左课本、右对话；复习 / 做题时课本自动收起，把屏幕让给对话
- **答案默认收起**，逐个点开对照；教材内搜索高亮；小芽提到出处时自动定位到课本位置
- **教材与课程标准锚定**，内置答案泄漏防护（命中会重写并打标）
- **首次运行配置界面**（含连通性测试）
- 开发期有 42 项界面自动化断言（渲染、交互、布局、降级、配置界面）

## 已知限制（老实说）

- 教材内容是**演示占位文本**，不是真实课本原文——内容工程尚未开工
- **学情不落库**：关掉软件，对话与掌握度不保留（存储待开发）
- 未做代码签名与自定义图标；目前**只有 Windows 便携版**，macOS 未构建
- 需要自备 DeepSeek API Key（软件本身不含 Key）

- 打包内容经解析检查：只含应用代码与运行依赖，**不含** `.env`、教材原文或研究材料
