# 芽问 SproutAsk v0.4.1

> 发布日期：2026-11-05。原生桌面壳与可用性修复版本。安装包未签名。

## 中文

这一版把学生端从「Edge 应用窗口」换成**自己的桌面程序**，并修掉两处会让页面卡死的会话问题。

**变更概览**：新增 1 项 · 优化 4 项 · 修复 3 项

**新增**

- **原生桌面壳**：`SproutAsk.exe`（Rust + WebView2）——双击即开，不再是浏览器窗口；单实例（重复启动只聚焦已有窗口，不会起第二个后台服务）、自带芽问图标与窗口标题、记住窗口大小与位置、关窗后自动结束本地服务。没有控制台黑窗。

**优化**

- 安装器：完成页「立即启动 SproutAsk」和「应用和功能」里的图标，都指向真实存在的 `SproutAsk.exe`（旧版指向不存在的 `launcher.vbs`，点了没反应、图标也是空的）。
- 小芽的回复改成学生话：短段落、不用 Markdown 标记、不出现「教材事实/来源」「我的解释」「disclosure」等标签或内部说法；对话气泡支持加粗与短列表，不再露出星号。
- 等待时有进度：页面准备与等待反馈会显示「已等 N 秒」，超过 20 秒会提示「比平时久一点」。
- 启动链路：桌面壳在隐藏窗口里完成首次初始化与本地服务启动，学生看不到命令行。
- 冲突提示改成学生话：「上一轮还没结束」——小芽还在回答上一题时不再整页报错。
- 服务不可用提示会提醒：刚填过 Key 需要重启芽问才生效。

**修复**

- 页面重载/重试时会话绑定抛 `TypeError` 导致整页卡死（`SESSION_RESUME_FAILED`）：现在任何会话绑定失败都会自动换一个不冲突的会话重试一次，教学上下文每轮由教育层重新注入，不丢记录。
- 「继续上次」重新打开学习台时不再先卡一分钟：已存在的会话 id 会先换成全新会话，不再触发 DSH 的恢复路径；创建会话另有 12 秒超时兜底。
- 等待时的秒数不再每秒重渲染整页（此前会吞掉按钮点击、打断滚动）。
- 小芽对话框改成正常聊天布局：消息区滚动、输入框固定在底部。
- 「下一题 / 跳过」现在真的会换到下一道题（此前活动 id 没传到宿主，永远停在第 1 题）。
- 帮助提示改成灰色小字，不再用整条黄色警告抢注意力；输入框有占位提示。
- 一次学习只记一条会话：跳过=做下一题（不再等于放弃本轮），重进/换题复用同一把学习的 session。
- 小芽看不到学生原话/模型乱编概念 id/工具永远报错：现在模型收到的是学生话和真实 id，`edu_submit_attempt` 真正可用；模型失败时如实说明「这次没能连上模型」，不再假装是正常反馈。
- 老用户的学习环境配置会随版本自动刷新（旧模板漏禁用的 DSH 界面元素不会再漏进学生页面）。
- 小芽现在知道学生刚提交的答案与判定：追问时直接针对所选选项讲，不再反问"你选的是哪一项"。
- 学生明确说"直接告诉我答案/选哪个"时，稳定给出完整答案并标记「这次看过完整答案」（不再依赖模型自觉）。
- 图片作答链路（选图 → 预览 → 发送 → 识别 → 澄清/判定）已实测可用。
- 等待反馈超过 12 秒时提示"可以继续等或取消"，等待期间题干与选项仍可阅读。
- 重复启动芽问（两个实例抢同一份本地日志锁）导致「暂时不能同时进行」：单实例壳从根上避免。
- 学习台打开/刷新时若上一轮还在回答，不再整页报错：显示「小芽还在回答上一题，稍等…」并自动重试。
- 桌面壳被强杀（任务管理器 / 崩溃）不再留下占着本地日志锁的孤儿 node：node 子进程放进 Job Object，宿主退出即一起结束。
- 安装后桌面/开始菜单快捷方式图标统一为芽问图标。

**质量门**

- CI 新增并保持全绿：`check:tracked`（源文件必须被 git 跟踪）、`contract:lock:verify`、`content:validate`、构建产物与已提交文件一致。

**重要说明**

- 安装包**未做代码签名**，Windows 会提示「未知发布者」；发布页附 `SHA256SUMS`。
- 原生桌面壳需要 **WebView2 Runtime**（Windows 11 自带；Windows 10 多数已随 Edge 安装）。
- 未做另一台干净机验证、未做学习效果实验。

## English

v0.4.1 replaces the Edge app window with a real desktop program and fixes two session bugs that could leave the study page stuck.

**Summary**: Added 1 · Improved 4 · Fixed 3

**Added**

- **Native desktop shell**: `SproutAsk.exe` (Rust + WebView2) — double-click to open, no browser window, no console flash; single instance (a second launch focuses the running window instead of starting another background service), own app icon and window title, remembers window size/position, and shuts the local service down on close.

**Improved**

- Installer: the finish-page "run" action and the Apps-list icon now point at the real `SproutAsk.exe` (the old installer pointed at a `launcher.vbs` that was never shipped).
- Startup: first-run setup and the local service start hidden behind the desktop window.
- Conflict copy: "the previous round is still running" instead of a full-page technical error.
- Unavailable-service copy now reminds students that a freshly saved API key takes effect after restarting the app.

**Fixed**

- A session-binding `TypeError` on reload/retry (`SESSION_RESUME_FAILED`) could blank the whole study page; binding failures now retry once with a fresh session id (the education layer re-injects its own context every turn, so records are kept).
- Launching SproutAsk twice made two processes compete for the same local journal lock ("can't do that right now"); the single-instance shell removes the root cause.
- Quick-launch icons now use the SproutAsk icon.

**Quality gates**

- CI now runs and stays green on: `check:tracked`, `contract:lock:verify`, `content:validate`, and a build-output drift check.

**Important notes**

- The installer is **not code-signed**; a `SHA256SUMS` file is provided.
- The native shell needs the **WebView2 Runtime** (bundled with Windows 11; usually present on Windows 10).
- No clean-machine validation and no learning-effect study yet.
