## 一、这是什么

SproutAsk 是基于 **真实 DSH 内核（@deepseek-ai/dsh 0.2.1-rc.3）** 的本地教育 Agent：学生在自己 Windows 电脑上，用人教版 2024 七年级上册生物学教材学习与复习，记录保存在本机。

- 内容：**2 单元 / 7 章 / 22 节 / 43 概念 / 88 活动 / 43 rubric / 44 关系 / 281 条出处**，已由用户本人以人类 curator 身份审校通过并发布（`pack.biology-7a.observation@2.0.0`，`status=published`）。
- 形态：本机后台服务 + 浏览器应用窗口（Edge `--app`），不需要 Electron、不需要管理员权限。
- 模型：DeepSeek 官方 API Key（`deepseek-flash`）；账户一键登录路线按用户决定**不提供**。

## 三、安装与首次使用

1. 双击 `SproutAsk-Setup-0.3.0-x64.exe`（**免管理员**，装到 `%LOCALAPPDATA%\SproutAsk\current`；未签名 → Windows 会提示"未知发布者"，选"仍要运行"）。
2. 开始菜单/桌面 **SproutAsk** 启动；首次启动会创建本地数据目录 `%LOCALAPPDATA%\SproutAsk\data`。
3. 打开后进 `/account` 粘贴 DeepSeek API Key → 保存（加密存本机，客户端不回显）→ **按提示重启应用**生效。
4. 未配 Key 时为"本地模式"：可读教材库、地图、记录，云推理不可用。
5. 卸载：设置→应用→SproutAsk；卸载会询问是否删除学习数据（默认保留）。
